## 画面の見方

- **左のカード**: 読み上げる文章を一つずつ入れます。カードごとに音源や設定を変えられます。
- **右の設定**: 選択中のカードの音源、言語、抑揚の強さ、モーラ長などです。
- **下のグラフ**: 読みの各モーラの高さと長さです（[抑揚と長さの編集](/editing/)）。
- **一番下の再生バー**: 再生・一時停止と再生位置です。

## カードを増やす・並べ替える

- 右下の「＋」または`Ctrl+D`でカードを追加します。
- カード右側のメニューで上下への移動と削除を行います。音源画像をドラッグしても並べ替えられます。
- `Delete`で選択中のカードを削除します。

## 再生する

画面下の再生ボタン、または`Ctrl+Enter`で選択中のカードを再生します。「再生」メニューでは、全カードを順に再生する「全テキストを再生」と、選択中のカードから最後までを再生する「選択中のテキストより先全てを再生」も選べます。

文章を入れると裏で音声の準備を始めます。準備中に再生ボタンを押しても、できしだい再生します。

## 音源を追加する

最初から「足立レイ ver3.5.0」が入っています。手持ちのUTAU音源を使うときは、音源フォルダをZIPにまとめ、「ファイル」→「音源とプラグイン」→「音源を追加...」で選びます。複数のZIPをまとめて選べます。

追加した音源はページを開いている間だけ使えます。ページを再読み込みしたときは、もう一度追加してください。音源の利用条件は、それぞれの音源の規約に従います。

## WAVを保存する

「ファイル」→「書き出し」から保存します。保存したファイルはブラウザのダウンロードとして保存されます。

- **WAVを保存...**: 選択中のカードの音声
- **WAVをすべて保存...**: 文章が入っているカードすべての音声（カードごとのファイル）
- **USTXとして書き出す...**: OpenUtauで開けるプロジェクト

## プロジェクトを保存する・開く

「ファイル」→「プロジェクトを保存」で、カードの文章・設定・編集内容を`.utautts`ファイルとしてダウンロードします。「プロジェクトを開く...」で`.utautts`を選ぶと続きから編集できます。プロジェクトはデスクトップ版とWeb版で共通です。

## キーボードショートカット

| 操作 | キー |
| --- | --- |
| 元に戻す | `Ctrl+Z` |
| やり直す | `Ctrl+Y` |
| 音声合成・再生 | `Ctrl+Enter` |
| プロジェクト保存 | `Ctrl+S` |
| テキスト追加 | `Ctrl+D` |
| テキスト削除 | `Delete` |

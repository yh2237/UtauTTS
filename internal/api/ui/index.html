MethodPath説明

      
        
GET/api/health稼働確認と既定Renderer

        
GET/api/voicebanks音源一覧（id・name・otoファイル数・エントリ数・診断数）

        
POST/api/voicebanks音源の登録（既定で無効・--allow-voicebank-registrationが必要）

        
POST/api/voicebanks/reload音源ディレクトリの再読込

        
GET/api/models抑揚モデル一覧

        
GET/api/renderersRenderer一覧と既定Renderer

        
POST/api/analyze文章→読み・モーラ列（{"text":"..."}、任意でdictionary）

        
POST/api/synthesize/audio単一発話の合成。WAVを返す。ヘッダーX-UtauTTS-Engine・X-UtauTTS-Reading

        
POST/api/synthesize/label単一発話の合成。HTK形式の音素ラベルを返す

        
POST/api/synthesize/batch複数発話の合成。ZIPを返す（16発話・256 MiBまで）

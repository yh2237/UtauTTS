# はじめに

Web版はインストール不要で、ブラウザから音声を合成できます。

## 動作環境

- Chrome・Edgeに対応しています。他のブラウザでも普通に動くと思います。
- エンジン・辞書・抑揚モデルなど、合計100MB以上を読み込みます。Wi-Fi環境で開いてください。
- 音声合成はブラウザ内で行い、入力文章や追加した音源はサーバーに送信しません。

## 使い方

1. [エディタ](/editor/){target="_self"}を開き、読み込みが終わるまで待ちます。
2. カードに文章を入力します。解析には時間がかかる場合があります。
3. 必要に応じて下部のグラフで音高と発音長を調整し、再生ボタンまたは `Ctrl + Enter` で音声を確認します。
4. 「ファイル」→「書き出し」→「WAVを保存...」でダウンロードします。

「足立レイ ver3.5.0」を同梱しています。ほかの音源を使う場合は[追加方法](/web/basics#音源を追加する)を参照してください。

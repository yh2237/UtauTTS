# はじめに

Web版はブラウザで利用でき、アプリのインストールは不要です。

## 動作環境

- Chrome・Edgeで使えます。ほかのブラウザでも動作する可能性があります。
- 初回はエンジン・辞書・抑揚モデルなど、合計100MB以上を読み込みます。Wi-Fi環境で開いてください。
- 音声合成はブラウザ内で行います。入力文章や追加した音源はサーバーに送信されません。

## 使い方

1. [エディタ](/editor/){target="_self"}を開き、読み込みが終わるまで待ちます。
2. カードに文章を入力し、下のグラフで音高と発音の長さを編集します。解析には時間がかかる場合があります。
3. 再生ボタンまたは`Ctrl+Enter`で音声を確認します。
4. 「ファイル」→「書き出し」→「WAVを保存...」でダウンロードします。

「足立レイ ver3.5.0」を同梱しています。ほかの音源を使う場合は[追加方法](/web/basics#音源を追加する)を参照してください。

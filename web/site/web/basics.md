# 基本の使い方

<!--@include: ../shared/basics.md-->

## 音源を追加する

音源フォルダのZIPを「ファイル」→「音源とプラグイン」→「音源を追加...」で選択します。複数のZIPを同時に追加できます。

追加した音源はページを開いている間だけ使えます。再読み込み後はもう一度追加してください。

## 書き出し

「ファイル」→「書き出し」からダウンロードします。

| 操作 | 出力内容 |
| :--- | :--- |
| **WAVを保存...** | 選択中カードの音声 |
| **WAVをすべて保存...** | 文章が入った全カードの音声を、カードごとに保存 |
| **USTXとして書き出す...** | OpenUtauのプロジェクト |

USTXの書き出しは開発途中で、一部に不具合があります。

## プロジェクトを保存する・開く

「ファイル」→「プロジェクトを保存」で、カードの文章・設定・編集内容を `.utautts` に保存します。

# 基本の使い方

<!--@include: ../shared/basics.md-->

## 音源を追加する

音源フォルダをZIPにまとめ、「ファイル」→「音源とプラグイン」→「音源を追加...」で選びます。複数のZIPをまとめて選べます。

追加した音源はページを開いている間だけ使えます。再読み込み後はもう一度追加してください。

## 書き出し

「ファイル」→「書き出し」から、ブラウザへファイルをダウンロードします。

- 「WAVを保存...」: 選択中のカードの音声
- 「WAVをすべて保存...」: 文章が入っている全カードの音声を、カードごとに保存
- 「USTXとして書き出す...」: OpenUtauのプロジェクトへ変換

USTXの書き出しは開発途中で、一部に不具合があります。

## プロジェクトを保存する・開く

「ファイル」→「プロジェクトを保存」で、カードの文章・設定・編集内容を`.utautts`としてダウンロードします。「プロジェクトを開く...」で保存したファイルを選ぶと、続きから編集できます。

# スマートフォン・タブレット

表示は画面幅に合わせて切り替わります。URL末尾に `?mobile=1` を付けるとスマートフォン向け、`?mobile=0` でパソコン向けに固定できます。

## 画面の見方

- カード設定: 右側の鉛筆ボタンで音源や抑揚を設定します。削除ボタンは設定の一番下にあります。
- 並べ替え: 音源画像を上下にドラッグします。
- 基本編集・拡張編集: グラフを指で操作します（[編集方法](/web/editing)）。
- 再生: 画面下部の再生バーを使います。
- 元に戻す・やり直す: 画面左上のボタンを使います。

## メニュー

画面右上の「☰」から、プロジェクトの保存・読込、書き出し、音源の追加、連続再生、設定などを選べます。[保存と書き出しの手順](/web/basics#書き出し)はパソコン向けの表示と共通です。

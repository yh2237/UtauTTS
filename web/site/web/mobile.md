# スマートフォン・タブレット

URL末尾に`?mobile=1`を付けるとスマートフォン向け、`?mobile=0`でパソコン向けの表示に固定できます。通常は画面幅に合わせて切り替わります。

## 画面の見方

- 上部の左に「元に戻す」「やり直す」、右に「☰」（メニュー）があります。
- カード右側の鉛筆ボタンで音源や抑揚などの設定を開きます。削除ボタンは設定の一番下にあります。
- 「基本編集」「拡張編集」のグラフは指で操作できます（[編集方法](/web/editing)）。
- 再生バーは一番下にあります。

音源画像を上下にドラッグするとカードを並べ替えられます。

## メニュー

「☰」から各操作を選びます。

| 見出し | 項目 |
| --- | --- |
| ファイル | プロジェクトを開く、プロジェクトを保存 |
| 書き出し | WAVを保存、WAVをすべて保存、USTXとして書き出す |
| 音源とプラグイン | 音源を追加、音源を再読込 |
| 再生 | 全テキストを再生、選択中のテキストより先全てを再生、もう一度再生 |
| 設定 | 設定、辞書設定 |
| ヘルプ | UtauTTSについて、GitHubリポジトリ、ライセンス、ボイスバンクの詳細、診断情報を書き出す、UtauTTSへようこそ |

書き出したファイルはブラウザのダウンロード先に保存されます。

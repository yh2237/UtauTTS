# トラブルシューティング

## 開くまでに時間がかかる

初回の読み込みには時間がかかります。止まったように見える場合は、ページを再読み込みしてください。

## 追加した音源が消えた

追加音源はページを開いている間だけ使えます。再読み込み後はもう一度ZIPを追加してください。音源を保存して使い続けたい場合は[デスクトップ版](/desktop/)を使ってください。

## デスクトップ版のみの機能

- Classic UTAU（UTAU互換のresamplerとwavtool）とDiffSingerでの合成
- AviUtl向けのexoの出力

Web版で保存した`.utautts`プロジェクトは、デスクトップ版で開いて編集を続けられます。

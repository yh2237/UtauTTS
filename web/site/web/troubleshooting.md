# トラブルシューティング

## 開くまでに時間がかかる

初回は100MB以上を読み込みます。読み込みが止まったように見える場合は、ページを再読み込みしてください。

## 追加した音源が消えた

Web版で追加した音源は、一度ページを閉じると使えなくなります。もう一度ZIPを追加してください。

## Web版で使えない機能

- Classic UTAU（UTAU互換のresamplerとwavtool）とDiffSingerでの合成
- AviUtl向けのexoの出力

これらの機能はデスクトップ版で利用できます。Web版で保存した `.utautts` プロジェクトも開けます。

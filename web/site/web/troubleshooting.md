# 困ったとき

## 開くまでに時間がかかる

初回は、エンジン・辞書・抑揚モデルなど、合わせて100MB以上を読み込みます。2回目以降はブラウザのキャッシュを使います。読み込みが止まったように見えるときは、ページを再読み込みしてください。

## 追加した音源が消えた

Web版で追加した音源は、ページを開いている間だけ使えます。ページを再読み込みしたときは、もう一度ZIPを追加してください。音源をいつでも使える状態にしておきたい場合は、[デスクトップ版](/desktop/)を使ってください。

## Web版にない機能を使いたい

次の機能はデスクトップ版だけにあります。

- Classic UTAU（UTAU互換のresamplerとwavtool）とDiffSingerでの合成
- AviUtl向けのexoの出力
- 音源フォルダを直接開く操作

プロジェクト（`.utautts`）はデスクトップ版と共通なので、Web版で作ったプロジェクトをデスクトップ版で続けられます。

## 不具合を報告する

エディタの「ヘルプ」→「診断情報を書き出す...」でダウンロードしたファイルを添えて、[GitHubのIssues](https://github.com/yh2237/UtauTTS/issues)へ報告してください。

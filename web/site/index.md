# はじめに

UtauTTSは、UTAU音源の声で日本語・英語・中国語の文章を読み上げるTTSです。Web版はブラウザで[エディタ](/editor/){target="_self"}を開くだけで使えます。デスクトップ版（Windows・macOS・Linux）は[GitHubのリリース](https://github.com/yh2237/UtauTTS/releases)から入手できます。

## 動作環境

- パソコンのChrome・Edgeで動作を確認しています。スマートフォンやタブレットのブラウザでも使えます（[スマートフォン・タブレット](/mobile)）。
- 初回はエンジン・辞書・抑揚モデルなど、合わせて100MB以上を読み込みます。2回目以降はブラウザのキャッシュを使うので早く開きます。
- 音声合成はすべてブラウザの中で行います。入力した文章や追加した音源はサーバーへ送りません。

## 最初の読み上げ

1. [エディタ](/editor/){target="_self"}を開き、読み込みが終わるまで待ちます。
2. 左上のカードに文章を入力します。入力すると自動で読みと抑揚を付け、画面下のグラフに表示します。
3. 画面下の再生ボタンを押すと、音声を作って再生します。パソコンでは`Ctrl+Enter`でも再生できます。
4. 気に入ったら「ファイル」→「書き出し」→「WAVを保存...」でダウンロードします。

最初は同梱の音源「足立レイ」で話します。ほかの音源を使う方法は[基本の使い方](/basics#音源を追加する)を参照してください。

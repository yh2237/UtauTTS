## 画面の見方

- カード: 読み上げる文章を入力し、カードごとに音源や設定を変更します。
- 設定欄: 選択中カードの設定を変更します。
- 編集グラフ: 音高と発音長を調整します（[編集方法](./editing)）。

## カードを増やす・並べ替える

- 追加: 右下の「＋」または `Ctrl + D`
- 並べ替え: 音源画像をドラッグ、またはカードのメニューで移動
- 削除: カードのメニュー、または選択中に `Delete` キー

## 再生する

再生ボタンまたは `Ctrl + Enter` で選択中カードを再生します。

| 「再生」メニュー | 動作 |
| :--- | :--- |
| **全テキストを再生** | 全カードを上から順に再生 |
| **選択中のテキストより先全てを再生** | 選択中カードから最後まで再生 |
| **もう一度再生** | 生成済みの音声を再生 |

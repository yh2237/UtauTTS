文章を入れると自動で抑揚と長さが付きます。気になるところだけを直してください。手で直した値は、再生しても保存しても維持されます。文章を変えると、読みと編集内容は新しい解析結果に置き換わります。

## 基本編集

画面下の「基本編集」では、読みの各モーラ（「こ」「ん」「に」…）の高さと長さを直します。

- 点を上下に動かすと、そのモーラの高さが変わります。グラフの縦の範囲は、抑揚の大きさに合わせて広がります。
- 縦線を左右に動かすと、モーラの境界が動いて長さが変わります。`Shift`を押しながら動かすと、後ろの境界も同じだけ動きます。
- 句読点などの休止にも境界線があり、長さを変えられます。休止に高さの点はありません。
- モーラ長の表示をダブルクリックすると、そのモーラと両隣が基本の長さに戻ります。点をダブルクリックすると、高さが自動の値に戻ります。

## 拡張編集

「拡張編集」では、波形、ノート、細かい抑揚線、原音ごとの設定を同じ時間軸で見ながら直します。

- 手のボタンを選ぶと、ノートを動かせます。上下に動かすと高さ、左右に動かすと発音位置、ノートの右端を動かすと長さが変わります。
- ペンのボタンを選ぶと（または`Ctrl`を押しながらドラッグすると）、抑揚線を細かく描き直せます。発音がない区間には線がありません。
- `PIT`と`VOL`は、原音ごとの高さと音量です。左右にドラッグして変えます。`VOL`は100が標準で、0にすると無音になります。

## カードごとの設定

右の設定は、選択中のカードだけに適用されます。

| 項目 | 内容 |
| --- | --- |
| 音源 | 使う音源 |
| 言語 | 日本語・英語・中国語 |
| 抑揚 | 自動で付ける抑揚の強さ。`0`で抑揚なし、`4`が標準で、上げるほど起伏が大きくなります（0〜8） |
| モーラ長／休止長 | 自動の値がないモーラの長さと、句読点などの休止の長さ |
| 文頭の長さ | 最初の音の前に取る長さ。先頭が欠けるときは長く、余計な音が入るときは短くします。通常は「自動」 |

発音形式、原音形式、抑揚モデル、音高は、通常は初期値のままで使えます。

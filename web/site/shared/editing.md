グラフで音高と発音の長さを編集します。文章を変更すると編集内容はリセットされます。

## 基本編集

| 操作 | 結果 |
| --- | --- |
| 点を上下へドラッグ | 音高を調整（±800セント） |
| 縦線を左右へドラッグ | 発音位置と長さを調整 |
| `Shift`＋縦線のドラッグ | 後ろの境界も同じ距離だけ移動 |
| 点をダブルクリック | 音高を自動値へ戻す |
| モーラ長表示をダブルクリック | そのモーラと両隣を基本長へ戻す |

休止の長さも編集できます。

## 拡張編集

ノートは手のボタンで編集します。

| 操作 | 結果 |
| --- | --- |
| ノートを上下へドラッグ | 音高を調整 |
| ノートを左右へドラッグ | 発音位置を調整 |
| ノートの右端を左右へドラッグ | 発音長を調整 |
| ペンを選んでドラッグ、または`Ctrl`＋ドラッグ | 抑揚線を描く |
| `PIT`／`VOL`を左右へドラッグ | 原音のピッチ係数／音量を調整 |

発音のない区間には抑揚線を描けません。

## カードごとの設定

設定は選択中のカードに適用されます。

| 項目 | 内容 |
| --- | --- |
| 言語 | 日本語・英語・中国語 |
| 抑揚 | 自動抑揚の強さ（0〜8）。`0`で無効、`4`が標準。日本語の既定モデルでは`2`で半分の強さ |
| モーラ長／休止長 | 自動の値がないモーラの長さと、句読点などの休止の長さ |
| 文頭の長さ | 通常は「自動」。先頭の音が欠ける場合は長く、余計な音が入る場合は短くする |

発音形式と原音形式は通常「自動」を使います。抑揚モデルは言語に応じて切り替わります。音高は音源の音階を選び、初期値は`C4`です。

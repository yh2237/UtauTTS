グラフで抑揚と発音の長さを編集します。文章を変更すると、編集内容は新しい解析結果に置き換わります。

## 基本編集

読みの各モーラ（「こ」「ん」「に」など）の高さと長さを調整します。

- 点を上下に動かすと高さが変わります。縦の表示・編集範囲は±800セントで固定です。
- 縦線を左右に動かすと、モーラの境界が動いて長さが変わります。`Shift`を押しながら動かすと、後ろの境界も同じだけ動きます。
- 句読点などの休止にも境界線があり、長さを変えられます。休止に高さの点はありません。
- モーラ長の表示をダブルクリックすると、そのモーラと両隣が基本の長さに戻ります。点をダブルクリックすると、高さが自動の値に戻ります。

## 拡張編集

波形、ノート、フレーム単位の抑揚線、原音ごとの設定を同じ時間軸で確認しながら編集します。

- 手のボタンでノートを動かします。上下で高さ、左右で発音位置、右端で長さを変えられます。
- ペンのボタン、または`Ctrl`を押しながらのドラッグで抑揚線を描き直します。発音がない区間は編集できません。
- `PIT`は原音ごとのピッチ係数、`VOL`は音量です。左右にドラッグして調整します。

## カードごとの設定

設定は選択中のカードに適用されます。

| 項目 | 内容 |
| --- | --- |
| 言語 | 日本語・英語・中国語 |
| 抑揚 | 自動抑揚の強さ（0〜8）。`0`でモデルの抑揚を無効、`4`が標準。日本語の既定モデルでは`2`で半分の強さになります |
| モーラ長／休止長 | 自動の値がないモーラの長さと、句読点などの休止の長さ |
| 文頭の長さ | 最初の原音に確保する先行発声。先頭が欠けるときは長く、余計な音が入るときは短くします。通常は「自動」 |

発音形式と原音形式は通常「自動」を使います。抑揚モデルは言語に応じて切り替わります。音高は`prefix.map`で使う音階で、初期値は`C4`です。

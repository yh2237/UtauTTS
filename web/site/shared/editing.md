文章を変更すると、音高と発音長の編集内容はリセットされます。

## 基本編集

| 操作 | 動作 |
| :--- | :--- |
| **制御点を上下にドラッグ** | 音高を調整（±800セント） |
| **境界線を左右にドラッグ** | 発音位置と長さを調整 |
| **`Shift` + 境界線をドラッグ** | 後続の境界線も同じ距離だけ移動 |
| **制御点をダブルクリック** | 音高を自動値にリセット |
| **モーラ長表示をダブルクリック** | 対象モーラとその前後を基本長にリセット |

休止の長さも編集できます。

## 拡張編集

ノートを編集するときは、手のボタンを選択します。

| 操作 | 動作 |
| :--- | :--- |
| **ノートを上下にドラッグ** | 音高を調整 |
| **ノートを左右にドラッグ** | 発音位置を調整 |
| **ノートの右端を左右にドラッグ** | 発音長を調整 |
| **ペンを選んでドラッグ、または `Ctrl` + ドラッグ** | 抑揚線を描画 |
| **`PIT` / `VOL` を左右にドラッグ** | 原音のピッチ係数 / 音量を調整 |

発音のない区間には抑揚線を描けません。

## カードごとの設定

| 項目 | 内容 |
| :--- | :--- |
| **言語** | 日本語・英語・中国語 |
| **抑揚** | 自動抑揚の強さ（0〜8、標準値 `4`）。`0` で無効。日本語の既定モデルでは `2` で半分の強さ |
| **モーラ長 / 休止長** | 自動値がないモーラの長さと、句読点などの休止長 |
| **文頭の長さ** | 通常は「自動」。先頭の音が欠ける場合は長めに、余計な音が入る場合は短めに設定 |

発音形式と原音形式は通常「自動」を使います。抑揚モデルは言語に応じて切り替わります。

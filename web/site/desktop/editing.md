# 抑揚と長さの編集

<!--@include: ../shared/editing.md-->

## 原音ごとの数値設定

「設定」→「設定...」で「拡張編集で数値設定を表示する」を有効にすると、拡張編集で選んだ原音のOffset、Cutoff、Consonant / Fixed、Preutterance、Overlap、ピッチ係数、音量係数、Velocity、Volume、Modulation、Tempo、Flagsを数値で調整できます。調整した値は、選んだ原音だけに適用されます。

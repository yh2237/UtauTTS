# 設定

「設定」→「設定...」で、新しいカードの初期値とアプリ全体の動作を変えます。「適用」は変更を反映して画面を開いたままにし、「OK」は反映して閉じます。「キャンセル」は保存していない変更を取り消します。

設定は、起動ファイルと同じ場所の`config.ini`に保存されます。

## 音声合成

新しいカードの初期値です。カードごとの設定は[抑揚と長さの編集](/desktop/editing#カードごとの設定)で変えます。

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| 音源 | 自動（一覧の先頭） | 新しいカードで使う音源 |
| 抑揚 | 4.00 | 自動で付ける抑揚の強さ（0〜8） |
| モーラ長 | 120 ms | モーラの基本の長さ |
| 休止長 | 180 ms | 句読点などの休止の長さ |
| 原音形式 | 自動 | 原音の選び方 |
| 抑揚モデル | `frame-intonation-tcn-v12` | 自動の抑揚を付けるモデル。英語と中国語では、それぞれの言語のモデルに切り替わります |
| Renderer | UtauTTS WORLD phrase | 原音をつないで音声にする方式 |
| 音高 | C4 | 新しいカードの基準の音高 |
| 文頭の長さ | 自動 | 最初の音の前に取る長さ |

文頭の長さは、「自動」のほかに5〜300 msの値にもできます。先頭が欠ける音源では長く、余計な音が入る音源では短くします。

### Rendererごとの設定

同じページに、Rendererごとのタブがあります。各タブには次の項目があります。

| 項目 | 内容 |
| --- | --- |
| タイミング | モーラ長、休止長、文頭の長さ |
| 抑揚 | 抑揚の強さと、子音の前後の小さな高さの動き |
| 音声補正 | 文末の音調、音源に合わせた伸縮、句読点に合わせた休止の長さ、読み上げの動きに合わせた伸縮。初期状態ではすべて有効です |
| 発音 | 英語の機能語を弱く読むかどうか |

「Classic UTAU」のタブでは使うresamplerとwavtool（[音源の追加](/desktop/voicebanks#classic-utauのresamplerとwavtool)）、「DiffSinger」のタブでは拡散のステップ数や表現力などを設定します。

## 書き出し

WAVと同じ場所に保存するファイルを選びます。初期状態ではどちらも無効です。

| 項目 | 内容 |
| --- | --- |
| WAVと一緒にテキストファイルを保存する | 入力した文章を`.txt`で保存します。文字コードはUTF-8かShift_JISを選べます |
| WAVと一緒に.labファイルを保存する | 音素ごとの開始・終了時刻を`.lab`で保存します |

WAVをすべて保存するときと、exoを出力するときにも適用されます。

## 表示と動作

テーマ、表示する言語、更新の通知、プレリリース版を更新の候補に含めるか、ログ、音声のキャッシュ、自動プレビューを設定します。

- 自動プレビューを有効にすると、抑揚や長さを編集したあとに自動で音声を作り直します。
- 「拡張編集で数値設定を表示する」を有効にすると、原音ごとの設定を数値で調整できます（[抑揚と長さの編集](/desktop/editing#原音ごとの数値設定)）。
- 外部のFFmpegを使う場合は、Qt Multimedia用のプラグインとコーデックが入ったフォルダを指定し、UtauTTSを起動し直してください。

## ショートカット

欄を選んでキーを押すと割り当てられます。`Backspace`で割り当てを外せます。同じキーを複数の操作に割り当てることはできません。初期のキーは[基本の使い方](/desktop/basics#キーボードショートカット)にあります。

## 辞書設定

自動の読みが違う固有名詞や略語は、「設定」→「辞書設定...」で表記と読みを登録して直します。

1. 「表記」に、文章中で置き換えたい文字列を入れます。
2. 「読み」に、読み上げたいひらがなまたはカタカナを入れます。
3. 「適用」で反映します。「OK」なら反映して閉じます。

| 表記 | 読み |
| --- | --- |
| `UtauTTS` | `うたうてぃーてぃーえす` |

登録した辞書は`config.ini`に保存され、次に起動したときも使われます。反映すると、入力済みの文章も新しい辞書で解析し直します。

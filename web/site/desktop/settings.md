# 設定

「設定」→「設定...」で新しいカードの初期値やアプリの動作を変更します。カードごとの値は[カードの設定](/desktop/editing#カードごとの設定)で変更します。

## 音声合成

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| 音源 | 自動（一覧の先頭） | 使用する音源 |
| 抑揚 | 4.00 | 自動で付ける抑揚の強さ（0〜8） |
| モーラ長 | 120 ms | モーラの基本の長さ |
| 休止長 | 180 ms | 句読点などの休止の長さ |
| 原音形式 | 自動 | 原音の選び方 |
| 抑揚モデル | `frame-intonation-tcn-v12` | 自動の抑揚を付けるモデル。言語に応じて切り替わる |
| Renderer | UtauTTS WORLD phrase | 原音をつないで音声にする方式 |
| 音高 | C4 | 新しいカードの基準の音高 |
| 文頭の長さ | 自動 | 最初の原音に確保する先行発声 |

### Rendererごとの設定

| 項目 | 内容 |
| --- | --- |
| タイミング | モーラ長、休止長、文頭の長さ |
| 抑揚 | 抑揚の強さと子音の前後の微細な音高変化 |
| 音声補正 | 文末の音調、音源に合わせた伸縮、句読点に応じた休止長、学習した時間配分に合わせた伸縮 |
| 発音 | 英語の機能語を弱く読むかどうか |

音声補正と英語機能語の弱形は初期状態で有効です。微細な音高変化と学習した時間配分に合わせた伸縮は、WORLD合成だけが使います。

「Classic UTAU」では[resamplerとwavtool](/desktop/voicebanks#classic-utauのresamplerとwavtool)、「DiffSinger」では拡散ステップ数や表現力を設定します。

## 書き出し

WAVと同時に保存する付随ファイルを選びます。初期状態では無効です。

| 項目 | 内容 |
| --- | --- |
| WAVと一緒にテキストファイルを保存する | 入力した文章を`.txt`で保存します。文字コードはUTF-8かShift_JISを選べます |
| WAVと一緒に.labファイルを保存する | 音素ごとの開始・終了時刻を`.lab`で保存します |

## ショートカット

欄を選んでキーを押すと割り当てられ、`Backspace`で解除できます。同じキーの重複はできません（[初期キー一覧](/desktop/basics#キーボードショートカット)）。

## 辞書設定

「設定」→「辞書設定...」で、自動読みが誤る語を登録します。

1. 「表記」に文章中の文字列を入力します。
2. 「読み」に発音を入力します。日本語はひらがなかカタカナ、英語・中国語は[発音記号・ピンイン](/desktop/languages#読みを直す)で指定します。
3. 「適用」で反映します。「OK」なら反映して閉じます。

| 表記 | 読み |
| --- | --- |
| `UtauTTS` | `うたうてぃーてぃーえす` |

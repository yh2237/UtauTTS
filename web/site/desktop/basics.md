# 基本の使い方

## 画面の見方

- 左のカードに、読み上げる文章を一つずつ入れます。カードごとに音源や設定を変えられます。
- 右には、選択中のカードの音源、言語、抑揚の強さ、モーラ長などの設定があります（[抑揚と長さの編集](/desktop/editing#カードごとの設定)）。
- 下のグラフには、読みの各モーラの高さと長さが出ます。
- 一番下の再生バーで、再生・一時停止と再生位置を操作します。

文章を入れると自動で解析し、読みと抑揚をグラフに表示します。

## カードを増やす・並べ替える

- 右下の「＋」または`Ctrl+D`でカードを追加します。
- 選択中のカードの右にあるメニューで、上下への移動と削除をします。音源画像をドラッグしても並べ替えられます。
- `Delete`で選択中のカードを削除します。

## 再生する

画面下の再生ボタン、または`Ctrl+Enter`で選択中のカードを再生します。「再生」メニューでは、次の再生も選べます。

- 「全テキストを再生」は、全カードを上から順に再生します。
- 「選択中のテキストより先全てを再生」は、選択中のカードから最後までを再生します。
- 「もう一度再生」は、作成済みの音声をもう一度再生します。

文章を入れると、裏で音声の準備を始めます。準備中に再生ボタンを押しても、準備ができしだい再生します。

## プロジェクトを保存する・開く

カードの文章、設定、編集した内容は、プロジェクト（`.utautts`）として保存できます。

- 「プロジェクトを保存」（`Ctrl+S`）は、今のプロジェクトに上書きで保存します。
- 「名前を付けてプロジェクトを保存...」は、保存先とファイル名を選んで保存します。
- 「プロジェクトを開く...」は、保存したプロジェクトを開きます。
- 「最近開いたプロジェクト」からは、最近開いたプロジェクトを一覧から選べます。

いずれも「ファイル」メニューにあります。プロジェクトはWeb版でも開けます。

WAVなどの書き出しは[書き出し](/desktop/export)を参照してください。

## キーボードショートカット

| 操作 | キー |
| --- | --- |
| 元に戻す | `Ctrl+Z` |
| やり直す | `Ctrl+Y` |
| 音声合成・再生 | `Ctrl+Enter` |
| プロジェクト保存 | `Ctrl+S` |
| 音源の再読み込み | `Ctrl+O` |
| テキスト追加 | `Ctrl+D` |
| テキスト削除 | `Delete` |

キーは「設定」→「設定...」で変えられます。同じキーを複数の操作に割り当てることはできません。

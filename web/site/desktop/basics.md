# 基本の使い方

<!--@include: ../shared/basics.md-->

## プロジェクトを保存する・開く

「ファイル」メニューで、カードの文章・設定・編集内容をプロジェクト（`.utautts`）として保存できます。プロジェクトはWeb版でも開けます。

WAVなどの書き出しは[書き出し](/desktop/export)を参照してください。

<!--@include: ../shared/shortcuts.md-->

音源の再読込は`Ctrl+O`です。キーの変更は[ショートカット設定](/desktop/settings#ショートカット)で行います。

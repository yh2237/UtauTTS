# 書き出し

書き出しは「ファイル」→「書き出し」から選びます。

## WAV

- 「WAVを保存...」: 選択中のカードの音声
- 「WAVをすべて保存...」: 文章が入っている全カードの音声を、カードごとに保存

設定を有効にすると、WAVと同じ場所にTXT・LABも保存できます（[書き出し設定](/desktop/settings#書き出し)）。

- 入力した文章のテキストファイル（`.txt`）
- 音素ごとの開始・終了時刻を書いた`.lab`ファイル。PSDToolKitなどの口パクに使えます。

## USTX

「USTXとして書き出す...」でOpenUtauのプロジェクト（`.ustx`）に変換します。

USTXの書き出しは開発途中で、一部に不具合があります。

## AviUtl向けのexo

カードごとのWAVと、音声を1つのレイヤーへ並べた`utautts.exo`を書き出します。

1. 「選択テキストをexoに出力...」または「全テキストをexoに出力...」を選びます。
2. AviUtlのプロジェクトと同じフレームレートと、WAVの保存先を指定します。
3. 表示された領域の中央をAviUtlの拡張編集へドラッグします。

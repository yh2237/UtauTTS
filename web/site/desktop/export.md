# 書き出し

書き出しは「ファイル」→「書き出し」から選びます。

## WAV

- 「WAVを保存...」は、選択中のカードの音声を保存します。
- 「WAVをすべて保存...」は、文章が入っているカードの音声を、カードごとのファイルにまとめて保存します。

設定で有効にすると、WAVと同じ場所に次のファイルも保存できます（[設定](/desktop/settings#書き出し)）。

- 入力した文章のテキストファイル（`.txt`）
- 音素ごとの開始・終了時刻を書いた`.lab`ファイル。PSDToolKitなどの口パクに使えます。

## USTX

「USTXとして書き出す...」で、OpenUtauで開けるプロジェクト（`.ustx`）に変換します。

## AviUtl向けのexo

AviUtlの拡張編集へ、カードごとの音声を並べて読み込めます。

1. 「選択テキストをexoに出力...」または「全テキストをexoに出力...」を選びます。
2. AviUtlのプロジェクトと同じフレームレートと、WAVの保存先を指定します。
3. カードごとのWAVと、1つのレイヤーに並べた`utautts.exo`が作られます。表示された領域の中央を、AviUtlの拡張編集へドラッグします。

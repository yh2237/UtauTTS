# 英語・中国語の読み上げ

英語と中国語の文章も読み上げられます。音源の収録形式に合う言語と発音形式を選んでください。

## 言語と発音形式

カードの「言語」を選びます。「発音形式」は通常「自動」を使います。

| 言語 | 発音形式 | 対応する音源 |
| --- | --- | --- |
| 日本語 | かな（`ja-kana`） | 日本語のUTAU音源 |
| 英語 | ARPAsing（`en-arpasing`）、Delta（`en-delta`）、VCCV（`en-vccv`）、C+V（`en-cv`） | それぞれの形式で収録した英語音源 |
| 中国語 | CVVC（`zh-cvvc`） | 中国語のCVVC音源 |

## 英語の合成

英語は原音をつながずに合成します。英語の音声合成（Kokoro-82M）に文を読ませ、その声に近い部分を音源の録音から選んで、音源の声で読み直します。

録音から声を選ぶために、音源ごとに録音を解析した索引を作ります。言語が英語と判定されない音源で英語を使うと、初めて合成するときに索引を作るため時間がかかります。

Web版では英語を合成できません。

## 読みを直す

自動の読みが誤る語は、[辞書設定](/desktop/settings#辞書設定)で直します。英語は発音記号（ARPAbet）、中国語は声調付きのピンインを入力します。

| 言語 | 読みの例 |
| --- | --- |
| 英語 | `HH AH0 L OW1 \| W ER1 L D` |
| 中国語 | `ni3 hao3` |

英語の空白は音素の区切り、`|`は単語の境界です。母音の後の数字は強勢で、`0`は強勢なし、`1`は第一強勢です。中国語は空白で音節を区切り、数字で声調を表します。

読みの生成規則とCLIでの指定方法は[日本語・英語・中国語の読み上げ](https://github.com/yh2237/UtauTTS/blob/main/docs/multilingual.md)を参照してください。

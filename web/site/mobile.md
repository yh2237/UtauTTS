# スマートフォン・タブレット

画面の幅が768pxより狭いと、エディタは自動でスマートフォン向けの画面になります。URLの末尾に`?mobile=1`を付けるとスマートフォン向け、`?mobile=0`を付けるとパソコン向けの画面に固定できます。

## 画面の見方

- **上の帯**: 左に「元に戻す」「やり直す」、右に「☰」（メニュー）があります。
- **カード**: 文章を入れます。右の鉛筆ボタンで、そのカードの設定（音源、抑揚の強さなど）を開きます。カードの削除も設定の一番下にあります。
- **グラフ**: 「基本編集」「拡張編集」は、パソコン向けの画面と同じように指で操作します。
- **再生バー**: 一番下にあります。

カードは、音源画像を指で上下にドラッグすると並べ替えられます。

## メニュー

「☰」のメニューは、パソコン向けの画面のメニューバーと同じ順に並んでいます。

| 見出し | 項目 |
| --- | --- |
| ファイル | プロジェクトを開く、プロジェクトを保存 |
| 書き出し | WAVを保存、WAVをすべて保存、USTXとして書き出す |
| 音源とプラグイン | 音源を追加、音源を再読込 |
| 再生 | 全テキストを再生、選択中のテキストより先全てを再生、もう一度再生 |
| 設定 | 設定、辞書設定 |
| ヘルプ | UtauTTSについて、GitHubリポジトリ、ライセンス、ボイスバンクの詳細、診断情報を書き出す、UtauTTSへようこそ |

保存したファイルは、端末のブラウザのダウンロードとして保存されます。

UtauTTS Windows GUI third-party addendum
========================================

This file supplements THIRD_PARTY_NOTICES.txt in the Windows GUI package. It
applies only to the Qt libraries, Qt Multimedia runtime configuration, and MinGW runtime
files bundled with that package.

FFmpeg runtime
===============

FFmpeg integration: Qt Multimedia uses the native Windows backend when
available. An external Qt Multimedia FFmpeg backend can be selected in
Settings or by setting UTAUTTS_FFMPEG_PATH, FFMPEG_PATH, FFMPEG_DIR, or
FFMPEG_ROOT before the first launch.

Backend path contents: the Qt Multimedia FFmpeg plugin and its codec libraries.
The command-line ffmpeg executable and the Qt Multimedia plugin are separate
interfaces. Qt SBOM JSON location: build audit output. Package notice:
licenses/Qt/FFmpeg-OPTIONAL.txt.

Qt and FFmpeg references:
https://doc.qt.io/qt-6.8/qtmultimedia-index.html
https://ffmpeg.org/legal.html


MinGW runtime libraries
=======================

The Windows GUI distribution includes MinGW runtime DLLs supplied by the Qt
toolchain. The exact GCC, MinGW-w64, and winpthreads license files from the
toolchain used by the build are included under licenses/MinGW.

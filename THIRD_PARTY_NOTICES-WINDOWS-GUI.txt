UtauTTS Windows GUI third-party addendum
========================================

This file supplements THIRD_PARTY_NOTICES.txt in the Windows GUI package. It
applies only to the Qt libraries, Qt Multimedia deployment, and MinGW runtime
files bundled with that package.

FFmpeg libraries distributed by Qt Multimedia
==============================================

The Windows GUI distribution includes the FFmpeg DLLs delivered by the Qt
Multimedia deployment (avcodec-61.dll, avformat-61.dll, avutil-59.dll,
swresample-5.dll, swscale-8.dll, and ffmpegmediaplugin.dll in the current build).
The exact Qt version, deployment provenance, and source/license links are
included under licenses/Qt. The exact FFmpeg source/build corresponding to these
files can be requested using the written source offer there.
FFmpeg is generally LGPLv2.1-or-later, but optional GPL components change the
applicable terms. Refer to the FFmpeg license and corresponding source for the
exact binary build:
https://ffmpeg.org/legal.html


MinGW runtime libraries
=======================

The Windows GUI distribution includes MinGW runtime DLLs supplied by the Qt
toolchain. The exact GCC, MinGW-w64, and winpthreads license files from the
toolchain used by the build are included under licenses/MinGW.

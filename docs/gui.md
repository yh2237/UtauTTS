# GUIの使い方

同梱音源を選んだまま文章を入力し、`Ctrl+Enter`または再生ボタンを押します。解析が終わるとグラフにイントネーションとモーラ長が表示されるので、必要な部分だけ編集してWAVへ保存します。

## 音源と文章

音源の配置は[インストール](installation.md)を参照してください。「ファイル」メニューから音源、Resamplers、Wavtoolsの各フォルダを開けます。配置後は同じメニューから音源またはClassic UTAUツールを再読み込みします。

左側のカードに文章を入力します。

- 右下の「追加」または`Ctrl+D`でカードを追加します。
- カード右側のメニューで上下への移動と削除を行います。音源画像のドラッグでも並べ替えられます。
- `Delete`で選択中のカードを削除します。キーは設定で変更できます。

カードを変更するとプロジェクトは未保存になります。

## カードごとの合成設定

右側の設定は選択中のカードだけに適用されます。アプリ全体の初期値は[設定](settings.md)で変更できます。

- **音源**: 使用するボイスバンク。
- **言語／phonemizer**: 開発者モードで表示されます。日本語は`ja-kana`、英語は`en-arpasing`／`en-delta`／`en-vccv`、中国語は`zh-cvvc`を使います。音源に合う組み合わせを選んでください。
- **原音形式**: `自動`、`従来互換`、`CVVC明瞭化`、`VCV優先`、`CVVC優先`、`単独音のみ`から選びます。通常は`自動`で音源に合わせます。`従来互換`と`CVVC明瞭化`は比較用です。
- **抑揚モデル**: 日本語の自動イントネーションと、対応モデルではモーラ長を予測します。`frame-intonation-v8`はピッチ、`prosody-multitask-v1`はピッチと長さを扱います。英語・中国語では日本語の学習モデルを使いません。
- **Renderer**: 合成方式を選びます。通常は`UtauTTS WORLD phrase`を使います。`Classic UTAU`ではResamplerとWavtoolの欄も表示します。
- **音高**: `prefix.map`で使用する音階。
- **抑揚**: 自動イントネーションの強さ。`0`で無効、`2`が標準で、2より上では変化を強調します。
- **モーラ長／休止長**: 自動値がないモーラの長さと、句読点などの休止時間。
- **文頭の長さ**: 最初の原音に確保する先行発声。先頭が欠ける音源では長く、余計なノイズを拾う場合は短くします。通常は`自動`です。

文章の解析が終わると、自動値がグラフへ反映されます。手動で変更した値は再生時も維持されます。

言語とphonemizerの詳細は[多言語TTS](multilingual.md)を参照してください。これらの項目は試験実装のため、通常は開発者モードを有効にしたときだけ表示されます。

## イントネーションとモーラ長

画面下部のグラフで読みの各モーラを編集します。

- 点を上下へ動かすと、そのモーラの手動ピッチ補正が変わります。
- 点の位置にある縦線を左右へ動かすと、モーラの境界と長さが変わります。
- `Shift`を押しながら境界線を動かすと、後ろの境界も同じ距離だけ動きます。
- 句読点などの休止にも境界線があり、休止長を編集できます。休止にはピッチ点がありません。
- モーラ長表示をダブルクリックすると、そのモーラと両隣が基本長へ戻ります。
- `Ctrl+Z`／`Ctrl+Y`でピッチとモーラ長の編集を戻したりやり直したりできます。

長い文章はグラフ下部の横スクロールバーで移動できます。文章を変更すると読みと編集点は新しい解析結果に置き換わります。

## 再生、保存、連携

「再生」メニューから選択中、全テキスト、選択位置より後ろのテキストを再生できます。「もう一度再生」はキャッシュ済み音声を使います。

「ファイル」→「WAVを保存...」で選択中のカードを保存し、「WAVをすべて保存...」で文章が入ったカードをまとめて保存します。TXT／LABを同時に保存する設定は[設定](settings.md#書き出し)を参照してください。

プロジェクトは「プロジェクトを保存」で`.utautts`へ保存し、「プロジェクトを開く...」で読み込みます。保存先を変えるときは「名前を付けてプロジェクトを保存...」を使います。最近開いたプロジェクトは「ファイル」メニューから選べます。

### exo出力

「ファイル」→「選択テキストをexoに出力...」または「全テキストをexoに出力...」を選び、AviUtlプロジェクトと同じフレームレート、WAV保存先を指定します。文章ごとのWAVと、1レイヤーへ並べた`utautts.exo`が作られます。表示された領域の中央をAviUtl拡張編集へドラッグしてください。

## 標準ショートカット

| 操作 | 初期ショートカット |
| --- | --- |
| 元に戻す | `Ctrl+Z` |
| やり直す | `Ctrl+Y` |
| 音声合成 | `Ctrl+Enter` |
| プロジェクト保存 | `Ctrl+S` |
| 音源再読み込み | `Ctrl+O` |
| テキスト追加 | `Ctrl+D` |
| テキスト削除 | `Delete` |

ショートカットは「設定」→「設定...」で変更できます。同じキーを複数の操作へ割り当てることはできません。

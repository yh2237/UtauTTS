# GUIの使い方

## 音源とカードの操作

- カードの並べ替え: 左側の音源アイコンをドラッグします。
- カードの削除: 選択中のカードの右上のメニューか、`Delete` キーで削除します。
- 音源の追加と再読込: 「ファイル」→「音源とプラグイン」から行います。配置方法は [インストール](installation.md#ボイスバンクの追加) を参照してください。

## カードごとの合成設定

画面右側で、選択中のカードの合成設定を変えます。新しいカードの初期値は「設定」画面で変えられます。

| 項目 | 内容 |
| :--- | :--- |
| 音源 | UTAU音源。 |
| 言語 | 日本語・英語・中国語・スペイン語・ポルトガル語。音源の情報から自動で判定します（スペイン語とポルトガル語は判定しません）。 |
| 方式 | 日本語は `波形合成`、英語・中国語・スペイン語・ポルトガル語は `（beta）参照照合` で合成します。参照照合では、休止長・原音形式・抑揚モデル・文頭の長さは使わないので表示しません。 |
| 発音形式 | 通常は `自動` のままで問題ありません。 |
| 原音形式 | 原音の接続方式（`自動`、`CVVC明瞭化`、`VCV優先`、`CVVC優先`、`単独音のみ`）。 |
| 抑揚モデル | イントネーションを予測するモデル。言語に合わせて切り替わります。 |
| 音高（Tone） | 読み上げの基準の音程を指定します。音程ごとの原音がある音源では、近い音程の原音を使います。 |
| 抑揚 | イントネーションの強さ（0〜8、標準値 `4`。`0` で抑揚なし）。 |
| モーラ長 / 休止長 | 1拍の基本の長さと、句読点の無音の長さ（ミリ秒）。 |
| 文頭の長さ | 先頭の原音の先行発声の余白。語頭が欠けるときは長めに、不要なノイズが入るときは短めにします。 |

数値のスライダーはダブルクリックで初期値に戻ります。

## 基本編集

| 操作 | 動作 |
| :--- | :--- |
| 制御点を上下にドラッグ | そのモーラの音高を調整 |
| 境界線を左右にドラッグ | 発音のタイミングと長さを調整 |
| `Shift` + 境界線をドラッグ | 後ろの境界線もまとめて移動 |
| モーラ長のラベルをダブルクリック | そのモーラと前後のモーラを基本の長さに戻す |

文章を書き換えると読みを解析し直し、手で編集した内容はリセットされます。

## 拡張編集（ノート・エンベロープ）

| 操作 | 動作 |
| :--- | :--- |
| ノートをドラッグ | 上下で音高、左右でタイミング、右端のドラッグで長さを調整 |
| ノートをダブルクリック | 手動の音高補正をリセット |
| ペンツール（または `Ctrl` + ドラッグ） | 自由曲線でピッチを描く |
| `PIT` / `VOL` スライダー | 原音ごとのピッチ係数と音量を調整（`VOL`は100が標準） |
| ホイール / `Ctrl` + ホイール | 横スクロール / タイムラインの拡大・縮小 |

「設定」→「設定...」で「拡張編集で数値設定を表示する」を有効にすると、選択した原音の設定を数値で入力できます。

## 再生と書き出し

- WAVと一緒にTXTとLABを保存する設定は、[外観の設定](settings.md#1-外観) にあります。
- USTX書き出しはOpenUtauのプロジェクトファイル形式で出力します。
- exo出力: 「選択テキストをexoに出力...」か「全テキストをexoに出力...」で、AviUtlのプロジェクトと同じフレームレートと、WAVの保存先を指定します。文章ごとのWAVと、それらを1レイヤーに並べた `utautts.exo` ができます。表示されたダイアログの中央をAviUtlの拡張編集のタイムラインへドラッグ＆ドロップすると、音声オブジェクトが配置されます。

## 標準ショートカット

初期値は[ショートカットの設定](settings.md#3-ショートカット)にあります。設定画面で変えられます。

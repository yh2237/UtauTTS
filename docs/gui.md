# GUIの使い方

文章を入力し、`Ctrl+Enter`または再生ボタンで音声を確認します。音高や発音の長さは画面下部で編集できます。

## 音源と文章

「ファイル」→「音源とプラグイン」で音源を追加・再読み込みできます。追加方法は[インストール](installation.md#ボイスバンクの追加)を参照してください。

左側のカードに文章を入力します。

- 「追加」または`Ctrl+D`でカードを追加します。
- 音源画像をドラッグするとカードを並べ替えられます。
- カードのメニューで移動・削除できます。`Delete`でも選択中のカードを削除できます。

## カードごとの合成設定

右側で選択中のカードの合成設定を変えます。新しいカードの初期値は[設定](settings.md)で変更します。

| 項目 | 内容 |
| --- | --- |
| 音源 | 読み上げに使うUTAU・DiffSinger音源を選択 |
| 言語 | 日本語・英語・中国語を選択。音源に言語情報があれば自動で反映 |
| 発音形式 | 通常は`自動`。音源に合う形式を手動で指定することも可能 |
| 原音形式 | 通常は`自動`。`CVVC明瞭化`、`VCV優先`、`CVVC優先`、`単独音のみ`へ変更可能 |
| 抑揚モデル | 自動イントネーションのモデルを選択。言語を変えると、対応モデルがあれば切り替わる |
| Renderer | 合成方式を選択。通常は`UtauTTS WORLD phrase`。他の方式は[Renderer設定](settings.md#renderer設定)を参照 |
| 音高 | 使用する音源の音階を選択 |
| 抑揚 | 自動イントネーションの強さ（0〜8）。`0`で無効、`4`が標準。既定モデルでは`2`で半分の強さ |
| モーラ長／休止長 | 自動値がないモーラの長さと、句読点などの休止時間 |
| 文頭の長さ | 通常は`自動`。先頭の音が欠ける場合は長く、余計なノイズが入る場合は短くする |

数値スライダーはドラッグや矢印キーで調整し、ダブルクリックで初期値へ戻せます。

言語と発音形式の詳細は[日本語・英語・中国語の読み上げ](multilingual.md)を参照してください。

## 基本編集

| 操作 | 結果 |
| --- | --- |
| 点を上下へドラッグ | モーラの音高を調整 |
| 縦線を左右へドラッグ | 発音位置と長さを調整 |
| `Shift`＋縦線のドラッグ | 後ろの境界も同じ距離だけ移動 |
| モーラ長表示をダブルクリック | そのモーラと両隣を基本長へ戻す |
| 下部のスクロールバーを動かす | 横へスクロール |

休止の長さも編集できます。先頭の発音位置は固定ですが、長さは変更できます。文章を変更すると読みを再解析し、編集内容をリセットします。

## 拡張編集

ノートは手のボタンで編集します。合成すると波形も表示されます。

| 操作 | 結果 |
| --- | --- |
| ノートを上下へドラッグ | 音高を調整 |
| ノートを左右へドラッグ | 発音位置を調整 |
| ノートの右端を左右へドラッグ | 発音長を調整 |
| ノートをダブルクリック | 手動の音高補正をリセット |
| ペンを選んでドラッグ、または`Ctrl`＋ドラッグ | 抑揚線を描く |
| `PIT`／`VOL`を左右へドラッグ | 原音のピッチ係数／音量を調整 |
| ホイール | 横へスクロール |
| `Ctrl`＋ホイール | 拡大・縮小 |

先頭の発音位置は動かせません。発音のない区間には抑揚線を描けません。`VOL`は100が標準で、0にすると無音になります。

「設定」→「設定...」で「拡張編集で数値設定を表示する」を有効にすると、選択した原音の設定を数値で調整できます。

## 再生、保存、連携

「再生」メニューで選択中のカード、全カード、選択中以降のカードを再生できます。「もう一度再生」は生成済みの音声を再生します。生成中に再生ボタンを押すと、完了後に再生します。

「ファイル」→「書き出し」から保存します。

| 操作 | 結果 |
| --- | --- |
| WAVを保存... | 選択中のカードをWAVへ保存 |
| WAVをすべて保存... | 文章が入ったカードをまとめてWAVへ保存 |
| USTXとして書き出し... | 自動ピッチと手動補正をOpenUtauプロジェクトへ書き出す |

TXT／LABの同時保存は[書き出し設定](settings.md#書き出し)で有効にします。USTXでの合成音声がUtauTTSと完全に一致するわけではありません（[詳細](cli.md#ustxへの一括変換)）。

「プロジェクトを保存」で`.utautts`へ保存し、「プロジェクトを開く...」で読み込みます。保存先の変更は「名前を付けてプロジェクトを保存...」、最近開いたプロジェクトは「最近開いたプロジェクト」から選べます。

### exo出力

「ファイル」→「書き出し」→「選択テキストをexoに出力...」または「全テキストをexoに出力...」を選び、AviUtlプロジェクトと同じフレームレート、WAV保存先を指定します。文章ごとのWAVと、1レイヤーへ並べた`utautts.exo`が作られます。表示された領域の中央をAviUtl拡張編集へドラッグしてください。

## 標準ショートカット

| 操作 | 初期ショートカット |
| --- | --- |
| 元に戻す | `Ctrl+Z` |
| やり直す | `Ctrl+Y` |
| 音声合成 | `Ctrl+Enter` |
| プロジェクト保存 | `Ctrl+S` |
| ボイスバンク再読み込み | `Ctrl+O` |
| テキスト追加 | `Ctrl+D` |
| テキスト削除 | `Delete` |

ショートカットは「設定」→「設定...」で変更できます。同じキーを複数の操作へ割り当てることはできません。

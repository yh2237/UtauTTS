# GUIの使い方

文章を入力すると自動で解析され、画面下部にイントネーションと発音の長さが表示されます。必要な部分を編集し、`Ctrl+Enter`または再生ボタンで音声を確認してからWAVへ保存します。

## 音源と文章

音源の配置は[インストール](installation.md)を参照してください。「ファイル」メニューから音源、Resamplers、Wavtoolsの各フォルダを開けます。配置後は同じメニューから音源またはClassic UTAUを再読み込みします。

左側のカードに文章を入力します。

- 右下の「追加」または`Ctrl+D`でカードを追加します。
- カード右側のメニューで上下への移動と削除を行います。音源画像のドラッグでも並べ替えられます。
- `Delete`で選択中のカードを削除します。キーは設定で変更できます。

カードを変更するとプロジェクトは未保存になります。

## カードごとの合成設定

右側の設定は選択中のカードだけに適用されます。アプリ全体の初期値は[設定](settings.md)で変更できます。

- **音源**: 使用するUTAU音源またはDiffSinger音源。
- **言語**: 日本語・英語・中国語を選びます。音源の言語情報がある場合は音源の選択時に反映します。
- **発音形式**: 通常は`自動`を使います。音源のメタデータと原音名から収録形式を判定します。手動で固定する場合はプルダウンから形式を選びます。
- **原音形式**: `自動`、`CVVC明瞭化`、`VCV優先`、`CVVC優先`、`単独音のみ`から選びます。通常は`自動`で音源に合わせます。
- **抑揚モデル**: 自動イントネーションを予測します。日本語では`frame-intonation-tcn-v9.1-t`（既定）、`frame-intonation-tcn-v9-t`を使い、英語では`english-intonation-v1`を使います。中国語では言語の声調規則を使います。英語のカードで日本語モデルが選ばれていても、同じモデルフォルダに英語モデルがあれば自動で切り替わります。
- **Renderer**: 合成方式を選びます。通常は`UtauTTS WORLD phrase`を使います。Classic UTAUのResamplerとWavtoolは「設定」→「設定...」のRendererタブで選びます。
- **音高**: `prefix.map`で使用する音階。
- **抑揚**: 自動イントネーションの強さ。`0`で無効、`2`が標準で、2より上では変化を強調します。
- **モーラ長／休止長**: 自動値がないモーラの長さと、句読点などの休止時間。
- **文頭の長さ**: 最初の原音に確保する先行発声。先頭が欠ける音源では長く、余計なノイズを拾う場合は短くします。通常は`自動`です。

文章の解析が終わると、自動値がグラフへ反映されます。手動で変更した値は再生時も維持されます。

タイミング補正も右側の設定欄で変更できます。初期状態では無効で、既存プロジェクトに保存されている設定は維持されます。言語と発音形式の詳細は[日本語・英語・中国語の読み上げ](multilingual.md)を参照してください。

## 基本編集

「基本編集」では、読みの各モーラについてイントネーションと発音の長さを編集します。

- 点を上下へ動かすと、そのモーラの手動ピッチ補正が変わります。
- 点の位置にある縦線を左右へ動かすと、モーラの境界と長さが変わります。
- `Shift`を押しながら境界線を動かすと、後ろの境界も同じ距離だけ動きます。
- 句読点などの休止にも境界線があり、休止長を編集できます。休止にピッチ点はありません。
- モーラ長表示をダブルクリックすると、そのモーラと両隣が基本長へ戻ります。
- `Ctrl+Z`／`Ctrl+Y`でピッチとモーラ長の編集を戻したりやり直したりできます。

先頭の発音位置は固定されていますが、発音長は変更できます。長い文章はグラフ下部の横スクロールバーで移動できます。文章を変更すると、読みと編集内容は新しい解析結果に置き換わります。

## 拡張編集

「拡張編集」では、波形、ノート、フレーム単位の抑揚線、原音ごとの設定を同じ時間軸で確認できます。文章を解析した時点でノートを表示し、音声合成後は波形も表示します。

- 手のボタンでは、ノートの高さや発音位置、発音長、原音ごとの設定を編集します。
- ペンのボタンでは、発音が存在する区間の抑揚線をフレーム単位で編集します。発音がない区間には線を表示せず、編集もできません。
- ノートを上下へ動かすと音高が変わります。左右へ動かすと発音位置が変わります。
- ノートの右端を左右へ動かすと発音長が変わります。
- 先頭の発音位置は固定されていますが、右端を動かして発音長を変更できます。
- `PIT`は原音ごとのピッチ係数、`VOL`は原音ごとの音量です。`VOL`の標準値は100で、0にすると無音になります。

「設定」→「設定...」で「拡張編集で数値設定を表示する」を有効にすると、Offset、Cutoff、Consonant / Fixed、Preutterance、Overlap、ピッチ係数、音量係数、Velocity、Volume、Modulation、Tempo、Flagsを数値で調整できます。これらは選択した原音だけに適用されます。

## 再生、保存、連携

「再生」メニューから「選択中のテキストを再生」「全テキストを再生」「選択中のテキストより先全てを再生」を選べます。「もう一度再生」はキャッシュ済みの音声を使います。

「ファイル」→「WAVを保存...」で選択中のカードを保存し、「WAVをすべて保存...」で文章が入ったカードをまとめて保存します。TXT／LABを同時に保存する設定は[設定](settings.md#書き出し)を参照してください。

プロジェクトは「プロジェクトを保存」で`.utautts`へ保存し、「プロジェクトを開く...」で読み込みます。保存先を変えるときは「名前を付けてプロジェクトを保存...」を使います。最近開いたプロジェクトは「ファイル」メニューから選べます。

### exo出力

「ファイル」→「選択テキストをexoに出力...」または「全テキストをexoに出力...」を選び、AviUtlプロジェクトと同じフレームレート、WAV保存先を指定します。文章ごとのWAVと、1レイヤーへ並べた`utautts.exo`が作られます。表示された領域の中央をAviUtl拡張編集へドラッグしてください。

## 標準ショートカット

| 操作 | 初期ショートカット |
| --- | --- |
| 元に戻す | `Ctrl+Z` |
| やり直す | `Ctrl+Y` |
| 音声合成 | `Ctrl+Enter` |
| プロジェクト保存 | `Ctrl+S` |
| ボイスバンク再読み込み | `Ctrl+O` |
| テキスト追加 | `Ctrl+D` |
| テキスト削除 | `Delete` |

ショートカットは「設定」→「設定...」で変更できます。同じキーを複数の操作へ割り当てることはできません。

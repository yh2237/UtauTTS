# GUIの使い方

初めて試すなら同梱音源を選んだまま左側の文章欄へ文を入力して`Ctrl+Enter`を押します。解析が終わるとイントネーションとモーラ長が下のグラフへ表示されて、その設定で合成と再生が始まります。気になるところだけグラフで直して「ファイル」→「WAVを保存...」から保存。だいたいこの流れです。

## 起動と音源の追加

起動とボイスバンクの配置は[インストール](installation.md)を参照してください。「ファイル」→「音源フォルダを開く」で配置先を開き、「音源を再読込」で一覧へ反映できます。

## 文章の入力

左側のカードへ音声化したい文章を入力します。カードでできる操作は次のとおりです。

- 右下の「追加」ボタンか`Ctrl+D`でカードを追加します。
- カード右側の「⋮」メニューからカードを上下へ移動したり削除したりできます。
- 音源画像をドラッグするとカードを並べ替えられます。
- `Delete`で選択中のカードを削除します。割り当てはショートカット設定で変更できます。

カードを並べ替えたり削除したりするとプロジェクトは未保存状態になります。

## 音声合成の設定

右側の設定欄で選択中の文章ごとに次の項目を変更できます。

- 音源: 使用するボイスバンク
- 原音形式: `自動`（音源のVC/VCV収録比から選択）、`従来互換`（v0.0.9の選択・接続）、`CVVC明瞭化`（CVVC優先・sequential接続・VC音量35%）、`VCV優先`、`CVVC優先`、`単独音のみ`。通常は`自動`を使用します。
- 抑揚モデル: 自動イントネーションや自動モーラ長に使うモデル。`frame-intonation-v8`はフレーム単位のイントネーション、`prosody-multitask-v1`はv8系のイントネーションに加えてモーラ長を予測します。
- Renderer: 原音の接続とピッチ処理の方式。通常は既定の`OpenUTAU WORLDLINE-R faithful`を使います。`waveform`は原音の明瞭度を確認するときの比較基準、`OpenUTAU Classic faithful`は原音ごとのWorldline再合成と5点包絡線で接続する方式です。
- 音高: `prefix.map`で使用する音階
- 抑揚: 自動イントネーションの強さ。標準は2で、0にすると無効になります。2より上では予測された高低差をさらに強調します。
- モーラ長: 個々のモーラに自動値がない場合に使う基本長
- 休止長: 句読点などの休止時間
- 文頭の長さ: 最初の原音に確保する先行発声。通常は`自動`を使い、先頭の欠けや余計なノイズがある音源だけ手動で調整します

解析が終わると合成前に自動イントネーションと自動モーラ長がピッチグラフへ反映されます。気になるところがあればそのまま手動で調整できます。

## イントネーションとモーラ長の編集

画面下部のグラフでは読みの各モーラを確認できます。

- 点を上下へドラッグするとそのモーラの手動ピッチ補正が変わります。
- 点の位置にある縦線を左右へドラッグするとモーラの境界と長さが変わります。
- `Shift`を押しながら縦線を動かすとそのモーラ以降の縦線も同じ距離だけ動きます。
- グラフ下部のモーラ長表示をダブルクリックするとそのモーラと両隣のモーラが基本長へ戻ります。
- 抑揚とモーラ長の編集は元に戻す・やり直す操作の対象です。
- 文章を変更すると読みと編集点は新しい解析結果に合わせて作り直されます。

長い文章はグラフ下部の横スクロールバーで移動できます。句読点などの休止は編集点に表示されません。

## 再生と保存

メニューバーの「再生」から次を選べます。

- 選択中のテキストを再生
- 全テキストを再生
- 選択中のテキストより先をすべて再生
- もう一度再生（キャッシュ済み音声）

「ファイル」→「WAVを保存...」で選択中の音声を保存できます。「WAVをすべて保存...」なら文章が入力されているカードをまとめて合成して保存します。

TXT／LABも一緒に保存する場合は[設定](settings.md#書き出し)を参照してください。

プロジェクトは「ファイル」→「プロジェクトを保存」で`.utautts`ファイルへ保存し「プロジェクトを開く...」で読み込みます。

## exo出力とドラッグ＆ドロップ

「ファイル」→「選択テキストをexoに出力...」か「全テキストをexoに出力...」を選びます。最初にフレームレート指定ダイアログが開くのでAviUtlプロジェクトのフレームレートに合わせて指定してください。次にWAVの保存先ディレクトリを指定すると合成が始まります。

合成が終わると文章ごとのWAVと、それらを1レイヤーに並べた`utautts.exo`が書き出されます。「exoをドラッグ」ウィンドウの中央をAviUtlの拡張編集へドラッグしてください。

## 標準ショートカット

| 操作 | 初期ショートカット |
| --- | --- |
| 元に戻す | `Ctrl+Z` |
| やり直す | `Ctrl+Y` |
| 音声合成 | `Ctrl+Enter` |
| プロジェクト保存 | `Ctrl+S` |
| ボイスバンク再読み込み | `Ctrl+O` |
| テキスト追加 | `Ctrl+D` |
| テキスト削除 | `Delete` |

「設定」→「設定...」のショートカット欄で変更できます。同じキーを複数の操作へ割り当てることはできません。

設定画面の全項目は[設定](settings.md)にまとめています。

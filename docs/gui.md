# GUIの使い方

文章を入力し、`Ctrl + Enter` または再生ボタンを押すだけで音声を合成できます。ピッチ（音高）や発音の長さは画面下部のエディタで直感的に調整可能です。

## 音源とカードの操作

画面左側のカードリストでテキストを管理します。

- **カードの追加**: 「追加」ボタンまたは `Ctrl + D`
- **カードの並べ替え**: 左側の音源アイコンをドラッグ＆ドロップ
- **カードの削除**: カード右上のメニュー、または選択中に `Delete` キー
- **音源の追加・再読込**: 「ファイル」→「音源とプラグイン」メニューから行います（配置方法は [インストール](installation.md#ボイスバンクの追加) を参照）。

## カードごとの合成設定

画面右側のサイドバーで、選択中カードの合成パラメータを設定します（新規カードの初期値は「設定」画面で変更可能）。

| 項目 | 内容 |
| :--- | :--- |
| **音源** | 使用するUTAU音源またはDiffSinger音源を選択します。 |
| **言語** | 日本語・英語・中国語に対応（音源情報から自動判定されます）。 |
| **発音形式** | 通常は `自動` のままで問題ありません。必要に応じて手動固定も可能です。 |
| **原音形式** | 原音接続方式（`自動`、`CVVC明瞭化`、`VCV優先`、`CVVC優先`、`単独音のみ`）。 |
| **抑揚モデル** | イントネーション予測モデル。言語設定に連動して切り替わります。 |
| **Renderer** | 音声波形の合成エンジン。標準は `UtauTTS WORLD phrase` です。 |
| **音高（Tone）** | 音源の基準音階を指定します（例: `C4`）。 |
| **抑揚** | イントネーションの強さ（0〜8、標準値 `4`。`0` で抑揚なし）。 |
| **モーラ長 / 休止長** | 各拍の基本長および句読点の無音時間（ミリ秒）を指定します。 |
| **文頭の長さ** | 先頭原音の先行発声余白。語頭が欠ける場合は長めに、不要なノイズが入る場合は短めに設定します。 |

※各数値スライダーはダブルクリックで初期値にリセットできます。

## 基本編集

カードを選択すると、下部にモーラ（拍）ごとのピッチとタイミングが表示されます。

| 操作 | 動作 |
| :--- | :--- |
| **制御点を上下にドラッグ** | そのモーラの音高（ピッチ）を調整 |
| **境界線を左右にドラッグ** | 発音タイミングと長さを調整 |
| **`Shift` + 境界線をドラッグ** | 後続の境界線も連動して一括移動 |
| **モーラ長ラベルをダブルクリック** | 対象モーラとその前後を基本長にリセット |
| **下部スクロールバー** | タイムラインを横スクロール |

※文章テキストを書き換えると自動再解析が行われ、手動編集内容はリセットされます。

## 拡張編集（ノート・エンベロープ）

より細かい音素単位の調声や連続ピッチ描画を行う場合は、拡張編集モードを使用します。

| 操作 | 動作 |
| :--- | :--- |
| **ノートをドラッグ** | 上下で音高、左右でタイミング、右端ドラッグで長さを調整 |
| **ノートをダブルクリック** | 手動の音高補正をリセット |
| **ペンツール（または `Ctrl` + ドラッグ）** | 自由曲線でピッチを描画 |
| **`PIT` / `VOL` スライダー** | 原音ごとのピッチ係数・音量を調整（`VOL`は100が標準） |
| **ホイール / `Ctrl` + ホイール** | 水平スクロール / タイムラインの拡大・縮小 |

※「設定」→「設定...」で「拡張編集で数値設定を表示する」を有効にすると、選択した原音の設定を数値入力で調整できます。

## 再生と書き出し

- **再生メニュー**: 選択中カード、全カード、または選択位置以降を順次再生できます。
- **WAV保存**: 「ファイル」→「書き出し」→「WAVを保存...」（一括保存にも対応）。TXT／LABの同時保存は [書き出し設定](settings.md#4-書き出し) で有効化できます。
- **USTX書き出し**: OpenUtauプロジェクトファイル形式で出力します。
- **AviUtl連携（exo出力）**: 「選択テキストをexoに出力...」または「全テキストをexoに出力...」で、AviUtlプロジェクトと同じフレームレートとWAV保存先を指定します。文章ごとのWAVと、それらを1レイヤーへ並べた `utautts.exo` が作られます。表示されたダイアログ領域の中央をAviUtlの拡張編集タイムラインへドラッグ＆ドロップすると、音声オブジェクトが配置されます。

## 標準ショートカット

| 操作 | ショートカット |
| :--- | :--- |
| 元に戻す / やり直す | `Ctrl + Z` / `Ctrl + Y` |
| 音声合成（再生） | `Ctrl + Enter` |
| プロジェクト保存 | `Ctrl + S` |
| ボイスバンク再読み込み | `Ctrl + O` |
| テキストカード追加 | `Ctrl + D` |
| テキストカード削除 | `Delete` |

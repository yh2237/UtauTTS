# 設定リファレンス

「設定」→「設定...」の画面は「外観」「合成」「ショートカット」に分かれています。辞書は「設定」→「辞書設定...」です。

## 1. 外観

| 項目 | 初期値 |
| :--- | :--- |
| テーマ | ライト |
| 言語 | 自動 |
| オーディオ出力 | システムの既定値 |
| FFmpegのパス | 空 |
| 保持する音声キャッシュ | 32 |
| 編集後に自動で再合成する | 有効 |
| 拡張編集で数値設定を表示する | 無効 |
| 成功時にログを閉じる | 有効 |
| アップデートの確認と通知を行う | 有効 |
| プレリリース版も確認する | 無効 |

FFmpegのパスは、Qt Multimediaが使うプラグインとコーデックのフォルダです。変更したあとはアプリを再起動します。

WAVと一緒に保存するファイル:

| 項目 | 説明 |
| :--- | :--- |
| WAVと一緒にテキストファイルを保存する | 入力した文章を、WAVと同じ名前の `.txt` で保存 |
| テキストファイルの文字コード | UTF-8 または Shift_JIS（CP932） |
| WAVと一緒に.labファイルを保存する | 音素の開始・終了時刻をHTK形式の `.lab` で保存（PSDToolKitなどのリップシンク用） |

## 2. 合成（新しいカードの初期値）

### 一般

どの方式でも使います。

| 項目 | 初期値 | 説明 |
| :--- | :--- | :--- |
| 音源 | 足立レイ | 新しいカードの音源。足立レイがなければ一覧の先頭 |
| 音高 | 自動 | 新規カードの初期の音程 |
| 抑揚 | `4.00` | イントネーションの強さ（0〜8） |
| モーラ長 | `120 ms` | 1拍の基本の長さ |

### 波形合成

| 項目 | 初期値 | 説明 |
| :--- | :--- | :--- |
| 原音形式 | `自動` | 原音の選び方（VCV、CVVC優先など） |
| 抑揚モデル | `frame-intonation-tcn-v12` | イントネーションの予測モデル（`なし` で使わない） |

### タイミング・抑揚・音声補正

| 区分 | 項目 |
| :--- | :--- |
| タイミング | 休止長、文頭の長さ（先頭の原音の先行発声の余白） |
| 抑揚 | 子音の前後の小さな音高の動き（Micro-prosody） |
| 音声補正 | 文末の音調（疑問文の上昇など）、音源に合わせた伸縮（母音の伸ばしすぎの抑制）、句読点の休止長を文脈化、読み上げの動きに合わせた伸縮（モーラの中の時間の配分） |

文末の音調、音源に合わせた伸縮、子音の前後の小さな音高の動きは日本語だけに効きます。読み上げの動きに合わせた伸縮と、子音の前後の小さな音高の動きは、波形合成だけに効きます。

## 3. ショートカット

| 操作 | 初期値 |
| :--- | :--- |
| 音声合成 | `Ctrl+Enter` |
| プロジェクト保存 | `Ctrl+S` |
| ボイスバンク再読み込み | `Ctrl+O` |
| テキスト追加 | `Ctrl+D` |
| テキスト削除 | `Delete` |
| 元に戻す | `Ctrl+Z` |
| やり直す | `Ctrl+Y` |

同じキーを2つの操作に割り当てると、保存できません。項目を選んでから割り当てるキーを押します。Backspaceで無効にできます。

## 4. 辞書設定

「設定」→「辞書設定...」で、固有名詞や略語の読みを登録・修正できます。

読みは、日本語ならひらがなかカタカナ、英語ならARPAbet、中国語なら声調付きのPinyinで書きます。「適用」か「OK」を押すと、入力済みの文章も解析し直します。

| 表記 | 読み |
| :--- | :--- |
| `UtauTTS` | `うたうてぃーてぃーえす` |

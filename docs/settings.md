# 設定リファレンス

「設定」→「設定...」から、新規カードの初期値やアプリ全体の動作をカスタマイズできます。

## 1. 音声合成（新規カードの初期値）

| 項目 | 初期値 | 説明 |
| :--- | :--- | :--- |
| **音源** | 自動（一覧の先頭） | 新しいカードで選択されるデフォルトボイスバンク |
| **抑揚** | `4.00` | 自動イントネーションの強さ（0〜8） |
| **モーラ長** | `120 ms` | 各拍の基本発音長 |
| **休止長** | `180 ms` | 読点や記号による休止長 |
| **原音形式** | `自動` | 原音選択方式（VCV、CVVC優先等） |
| **抑揚モデル** | `frame-intonation-tcn-v12` | 自動イントネーション予測モデル（`なし` で無効化） |
| **Renderer** | `utautts-world-phrase` | 音声合成エンジン |
| **基準音高** | 自動 | 新規カードの初期の音程 |
| **文頭の長さ** | `自動` | 先頭原音の先行発声余白（自動、または5〜300 ms） |

## 2. Renderer設定

使用するRendererに応じた詳細挙動を設定します。

- **タイミング**: モーラ長、休止長、文頭余白の基準値
- **抑揚**: 抑揚強度、子音前後の微小ピッチ変動（Micro-prosody）の有無
- **音声補正**: 文末音調（疑問文上昇等）、母音過度伸長の抑制、文脈連動の休止長調整
- **Classic UTAU**: 外部ResamplerおよびWavtoolの選択
- **DiffSinger**: 拡散ステップ数、ピッチ・長さ混合率、表現力（詳細は [DiffSinger](diffsinger.md) を参照）

## 3. 辞書設定

「設定」→「辞書設定...」から、固有名詞や略語の読みを登録・修正できます。

1. **表記**: 読み替え対象の単語を入力します。
2. **読み**: 発音を入力します（日本語はひらがな/カタカナ、英語はARPAbet、中国語は声調付きPinyin）。
3. 「適用」または「OK」をクリックすると、入力済みの文章にも即座に再解析が適用されます。

| 表記 | 読み |
| :--- | :--- |
| `UtauTTS` | `うたうてぃーてぃーえす` |

## 4. 書き出し

| 項目 | 説明 |
| :--- | :--- |
| **テキストファイルを保存する** | WAV書き出し時に入力テキスト（`.txt`）を同名保存 |
| **テキストの文字コード** | UTF-8 または Shift_JIS（CP932）を選択 |
| **.labファイルを保存する** | 音素の開始・終了時刻をHTK形式（`.lab`）で保存（PSDToolKit等のリップシンク用） |

## 5. 表示と動作

- **テーマ / 言語**: ダーク/ライトテーマや表示言語の切り替え
- **自動プレビュー**: 基本編集・拡張編集でピッチや境界線を移動した際、自動で再合成
- **数値設定の表示**: 拡張編集モードで原音パラメータの数値直接入力を有効化
- **外部FFmpeg**: Qt Multimedia用のプラグイン・コーデックフォルダを指定（変更後はアプリを再起動）
- **ショートカット設定**: 各操作キーを割り当て可能（`Backspace` で割り当て解除）

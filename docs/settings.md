# 設定リファレンス

「設定」→「設定...」の画面は「表示と動作」「音声合成」「ショートカット」「索引」に分かれています。辞書は「設定」→「辞書設定...」です。

## 1. 表示と動作

| 項目 | 初期値 |
| :--- | :--- |
| テーマ | ライト |
| 言語 | 自動 |
| オーディオ出力 | システムの既定値 |
| FFmpegのパス | 空 |
| 保持する音声キャッシュ | 32 |
| 編集後に自動で再合成する | 有効 |
| 拡張編集で数値設定を表示する | 無効 |
| 成功時にログを閉じる | 有効 |
| アップデートの確認と通知を行う | 有効 |
| プレリリース版も確認する | 無効 |

FFmpegのパスはQt Multimediaが使うプラグインとコーデックのフォルダです。変更後はアプリを再起動してください。

| 項目 | 初期値 | 説明 |
| :--- | :--- | :--- |
| テキストファイルの文字コード | UTF-8 | TXTを書き出すときの文字コード（UTF-8 または Shift_JIS） |
| 書き出し先 | ドキュメント/UtauTTS | 「WAVとLABとTXTを書き出し先に保存」「WAVとLABとTXTを全て書き出し先に保存」で保存するフォルダ |
| 書き出し先の同名ファイルを上書きする | 無効 | 無効のときは番号を付けて別名で保存 |

TXTとLABは、「ファイル」→「書き出し」の「WAVとLABとTXTを保存」「WAVとLABとTXTを全て保存」「WAVとLABとTXTを書き出し先に保存」「WAVとLABとTXTを全て書き出し先に保存」で書き出します。

書き出し先に保存するときは、ダイアログを出さずに「音源名_文章.wav」として保存します。同名ファイルがある場合は「音源名_文章 (2).wav」のように連番を付与し、「書き出し先の同名ファイルを上書きする」が有効なら上書きします。

## 2. 音声合成（新しいカードの初期値）

### 一般

すべての方式で共通の設定です。

| 項目 | 初期値 | 説明 |
| :--- | :--- | :--- |
| 音源 | 足立レイ | 新しいカードの音源。足立レイがなければ一覧の先頭 |
| 音高 | 自動 | 新しいカードの初期音程 |
| 抑揚 | `4.00` | イントネーションの強さ（0〜8） |
| モーラ長 | `120 ms` | 1拍の基本の長さ |

### 波形合成

| 項目 | 初期値 | 説明 |
| :--- | :--- | :--- |
| 原音形式 | `自動` | 原音の選び方（VCV、CVVC優先など） |
| 抑揚モデル | `frame-intonation-tcn-v12` | イントネーションの予測モデル（`なし` で使わない） |

### タイミング・抑揚・音声補正

| 区分 | 項目 |
| :--- | :--- |
| タイミング | 休止長、文頭の長さ（先頭の原音の先行発声の余白） |
| 抑揚 | 子音の前後の小さな音高の動き（Micro-prosody） |
| 音声補正 | 文末の音調（疑問文の上昇など）、音源に合わせた伸縮（母音の伸ばしすぎの抑制）、句読点の休止長を文脈化、読み上げの動きに合わせた伸縮（モーラの中の時間の配分） |

文末の音調、音源に合わせた伸縮、子音の前後の小さな音高の動きは日本語のみ有効です。読み上げの動きに合わせた伸縮と、子音の前後の小さな音高の動きは波形合成のみ有効です。

## 3. ショートカット

| 操作 | 初期値 |
| :--- | :--- |
| 音声合成 | `Ctrl+Enter` |
| プロジェクト保存 | `Ctrl+S` |
| ボイスバンク再読み込み | `Ctrl+O` |
| テキスト追加 | `Ctrl+D` |
| テキスト削除 | `Delete` |
| 元に戻す | `Ctrl+Z` |
| やり直す | `Ctrl+Y` |
| 書き出し先に保存 | `Ctrl+E` |
| 全て書き出し先に保存 | `Ctrl+Shift+E` |

項目を選んでから割り当てるキーを押します。`Backspace` で無効にできます。同じキーを複数の操作に割り当てると保存できません。

## 4. 索引

参照照合で使う索引の一覧です。索引は音源ごとに作られ、音源名・モデル・バージョン・サイズ・更新日時が表示されます。

- 作成: 上部の作成ボタンで既定音源の索引を作成します。作成中は進捗が表示されます。
- 削除: 行の削除ボタンでその索引を削除します。次に参照照合を使うときに作り直されます。

索引は初回の合成やプレビューでも自動で作られます。音源を追加したあとに先に作っておくと、最初の読み上げを待たずに済みます。

## 5. 辞書設定

「設定」→「辞書設定...」で、固有名詞や略語の読みを登録・修正できます。

読みは、日本語ならひらがなかカタカナ、英語ならARPAbet、中国語なら声調付きのPinyinで書きます。「適用」か「OK」を押すと、入力済みの文章も解析し直します。

| 表記 | 読み |
| :--- | :--- |
| `UtauTTS` | `うたうてぃーてぃーえす` |

# 設定

メニューバーの「設定」→「設定...」ではこれから追加する文章カードの初期値とアプリ全体の動作を変更できます。「適用」で変更を反映し、「OK」で反映して画面を閉じます。「キャンセル」では反映していない変更を破棄します。

設定は`config.ini`へ保存されます。

## 音声合成

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| デフォルト音源 | 自動（一覧の先頭） | 新しい文章カードで使うボイスバンク。音源を固定したい場合は名前を選びます |
| デフォルト原音形式 | 自動 | 新しい文章カードで使う原音選択方式 |
| デフォルト抑揚モデル | `frame-intonation-v8` | 自動イントネーションに使うモデル。「なし」では原音のピッチを維持します |
| デフォルトRenderer | `utautts-world-phrase` | 原音の長さと高さを変え、接続してWAVにする方式 |
| デフォルト音高 | `C4` | 新しい文章カードで基準にする音高 |
| デフォルト抑揚 | 2.00 | 新しい文章カードへ設定する抑揚の強さ |
| デフォルトモーラ長 | 120 ms | モデルまたは手動編集で長さを指定していないモーラの長さ |
| デフォルト休止長 | 180 ms | 句読点などに割り当てる休止時間 |
| デフォルトの文頭の長さ | 自動 | 最初の原音で確保する先行発声。先頭が欠ける音源では長く、余計なノイズを拾う音源では短くします |
| 保持する音声キャッシュ | 32件 | 同じ条件の音声を再生するときに再利用する一時WAVの数。1件にすると直前の音声だけを保持します |

文頭の長さは0〜300 msの固定値にもできます。音源や文章ごとに変える場合は文章カード右側で指定します。

合成音声のキャッシュはアプリを終了すると削除されます。上限を減らした場合は古い音声から削除し、ボイスバンクを再読み込みした場合はすべて削除します。

Rendererごとの違いは[モデル／Rendererプラグイン](plugins.md)にあります。各カードの原音形式、音高、抑揚などは[GUIの使い方](gui.md#音声合成の設定)を参照してください。

「外部Renderer」の「追加」ではUTAU互換resamplerの実行ファイルを登録できます。外部Rendererは各原音の音高と長さを処理し、UtauTTSが5点包絡線で接続します。登録を削除しても実行ファイル自体は削除されません。合成時に外部プログラムを実行する機能なので、信頼できる配布元のものだけを追加してください。

## 書き出し

WAVを保存するとき同じ場所へ同名の付随ファイルも保存できます。どちらも初期状態では無効です。

| 項目 | 内容 |
| --- | --- |
| WAVと一緒にテキストファイルを保存する | 入力した文章を`.txt`で保存します |
| テキストファイルの文字コード | UTF-8またはShift_JIS（CP932）を選びます。LABには影響しません |
| WAVと一緒に.labファイルを保存する | 音素と開始・終了時刻をHTK形式の`.lab`で保存します |

一括WAV保存とexo出力にも適用されます。LABはHTK形式の推定音素境界で、PSDToolKitなどのリップシンクに利用できます。

## 表示

- テーマはライトとダークから選べます。
- 表示言語は日本語、English、中文に対応しています。
- 「アップデートの確認と通知を行う」が有効なら起動時にGitHub Releasesを確認します。更新しても`voice`、`config.ini`、追加した外部Rendererは残ります。
- 開発者モードを有効にすると「抑揚の教師データ生成」が追加されます。使い方は[手動調整から抑揚モデルを作る](prosody-model-training.md)にあります。

## ログ

「成功時にログを閉じる」が有効なら合成に成功したあと音声合成ログを自動で閉じます。無効にすると成功時の処理内容もそのまま確認できます。エラーが起きた場合は設定に関係なくログが残ります。

## ショートカット

変更したい欄を選んで割り当てるキーを押します。`Backspace`で割り当てを外せます。同じキーを複数の操作へ割り当てることはできません。

初期値は[GUIの使い方](gui.md#標準ショートカット)にまとめています。`Ctrl+Z`と`Ctrl+Y`で戻せるのはイントネーションとモーラ長の編集だけです。文章やカードの追加・削除・並べ替えは対象に含みません。

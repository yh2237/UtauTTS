# 設定

「設定」→「設定...」で、新しい文章カードの初期値とアプリ全体の動作を変更します。「適用」は変更を反映して閉じず、「OK」は反映して閉じます。「キャンセル」は今回の変更を破棄します。

設定は実行ファイルと同じ階層の`config.ini`へ保存されます。

## 音声合成

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| デフォルト音源 | 自動（一覧の先頭） | 新しいカードで使うボイスバンク |
| デフォルト原音形式 | 自動 | 原音の選択方式 |
| デフォルト抑揚モデル | `frame-intonation-v8` | 自動イントネーションのモデル。「なし」では予測しません |
| デフォルトRenderer | `utautts-world-phrase` | 原音を接続してWAVにする方式 |
| デフォルト音高 | `C4` | 新しいカードの基準音高 |
| デフォルト抑揚 | 2.00 | 自動イントネーションの強さ |
| デフォルトモーラ長 | 120 ms | 自動値がないモーラの長さ |
| デフォルト休止長 | 180 ms | 句読点などの休止時間 |
| デフォルトの文頭の長さ | 自動 | 最初の原音に確保する先行発声 |
| 保持する音声キャッシュ | 32件 | 再生に再利用する一時WAVの数 |

文頭の長さは0〜300 msの固定値にもできます。先頭が欠ける音源では長く、余計なノイズを拾う音源では短くします。カードごとの設定は[GUIの使い方](gui.md#カードごとの合成設定)で変更します。

キャッシュはアプリ終了時に削除され、音源を再読込すると全件破棄されます。上限を減らした場合は古いものから削除されます。

RendererとClassic UTAUツールの追加方法は[モデル／Rendererプラグイン](plugins.md)、辞書の登録方法は[辞書設定](dictionary.md)を参照してください。外部ツールは信頼できる配布元のものだけを使用してください。

## 書き出し

WAVと同じ場所へ付随ファイルを保存できます。初期状態では無効です。

| 項目 | 内容 |
| --- | --- |
| WAVと一緒にテキストファイルを保存する | 入力文章を`.txt`で保存 |
| テキストファイルの文字コード | UTF-8またはShift_JIS（CP932） |
| WAVと一緒に.labファイルを保存する | 音素の開始・終了時刻をHTK形式の`.lab`で保存 |

一括WAV保存とexo出力にも適用されます。LABはPSDToolKitなどのリップシンクに利用できます。

## 表示、ログ、ショートカット

- **表示**: テーマと表示言語を選べます。更新通知を有効にすると起動時にGitHub Releasesを確認します。開発者モードでは抑揚教師データ生成や試験的な多言語機能が使えます。
- **プレリリース版も確認する**: 開発者モードを有効にしたときだけ表示されます。既定では無効で、開発者モードとこの設定の両方を有効にした場合だけプレリリース版を更新候補に含めます。
- **ログ**: 「成功時にログを閉じる」を無効にすると、成功時の処理内容も残ります。エラー時は常にログが残ります。
- **ショートカット**: 欄を選んでキーを押すと割り当てられます。`Backspace`で解除できます。同じキーは複数の操作に割り当てられません。

初期ショートカットは[GUIの使い方](gui.md#標準ショートカット)にあります。`Ctrl+Z`／`Ctrl+Y`の対象はイントネーションとモーラ長の編集だけです。

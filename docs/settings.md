# 設定リファレンス

「設定」→「設定...」の項目です。

## 1. 音声合成（新規カードの初期値）

| 項目 | 初期値 | 説明 |
| :--- | :--- | :--- |
| 音源 | 自動（一覧の先頭） | 新しいカードの音源 |
| 抑揚 | `4.00` | イントネーションの強さ（0〜8） |
| モーラ長 | `120 ms` | 1拍の基本の長さ |
| 休止長 | `180 ms` | 読点や記号での休止の長さ |
| 原音形式 | `自動` | 原音の選び方（VCV、CVVC優先など） |
| 抑揚モデル | `frame-intonation-tcn-v12` | イントネーションの予測モデル（`なし` で使わない） |
| Renderer | `utautts-world-phrase` | 音声合成エンジン |
| 音高 | 自動 | 新規カードの初期の音程 |
| 文頭の長さ | `自動` | 先頭の原音の先行発声の余白（自動、または5〜300 ms） |

## 2. Renderer設定

項目はRendererによって変わります。

- タイミング: モーラ長、休止長、文頭の長さの基準値
- 抑揚: 抑揚の強さ、子音の前後の小さな音高の動き（Micro-prosody）の有無
- 音声補正: 文末の音調（疑問文の上昇など）、母音の伸ばしすぎの抑制、文脈に応じた休止長の調整
- Classic UTAU: 外部のResamplerとWavtoolの選択
- DiffSinger: 拡散ステップ数、ピッチと長さの予測の混合率、表現力（[DiffSinger](diffsinger.md) を参照）

## 3. 辞書設定

「設定」→「辞書設定...」で、固有名詞や略語の読みを登録・修正できます。

読みは、日本語ならひらがなかカタカナ、英語ならARPAbet、中国語なら声調付きのPinyinで書きます。「適用」か「OK」を押すと、入力済みの文章も解析し直します。

| 表記 | 読み |
| :--- | :--- |
| `UtauTTS` | `うたうてぃーてぃーえす` |

## 4. 書き出し

| 項目 | 説明 |
| :--- | :--- |
| WAVと一緒にテキストファイルを保存する | 入力した文章を、WAVと同じ名前の `.txt` で保存 |
| テキストファイルの文字コード | UTF-8 または Shift_JIS（CP932） |
| WAVと一緒に.labファイルを保存する | 音素の開始・終了時刻をHTK形式の `.lab` で保存（PSDToolKitなどのリップシンク用） |

## 5. 表示と動作

- FFmpegのパス: Qt Multimedia用のプラグインとコーデックのフォルダ。変更後はアプリを再起動します。

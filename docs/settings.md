# 設定

「設定」→「設定...」で、新しいカードの初期値とアプリの動作を変更します。「適用」で反映し、「OK」で反映して閉じます。「キャンセル」は未保存の変更を破棄します。

## 音声合成

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| 音源 | 自動（一覧の先頭） | 新しいカードで使うボイスバンク |
| 抑揚 | 4.00 | 自動イントネーションの強さ（0〜8） |
| モーラ長 | 120 ms | モーラの基本の長さ |
| 休止長 | 180 ms | 句読点などの休止時間 |
| 原音形式 | 自動 | 原音の選択方式 |
| 抑揚モデル | `frame-intonation-tcn-v12` | 自動イントネーションのモデル。`なし`で予測を無効にする |
| Renderer | `utautts-world-phrase` | 原音を接続してWAVにする方式 |
| 音高 | `C4` | 新しいカードの基準音高 |
| 文頭の長さ | 自動 | 最初の原音に確保する先行発声 |

文頭の長さは`自動`または5〜300 msを指定します。0は自動です。先頭の音が欠ける場合は長く、余計なノイズが入る場合は短くします。カードごとの変更は[合成設定](gui.md#カードごとの合成設定)で行います。

## Renderer設定

Rendererごとのタブで調整します。モーラ長・休止長・文頭の長さ・抑揚は新しいカードの初期値になり、カードごとに変更できます。

| 項目 | 変更できる内容 |
| --- | --- |
| タイミング | モーラ長・休止長・文頭の長さ |
| 抑揚 | 抑揚の強さと、子音の前後の小さな音高変化 |
| 音声補正 | 文末の音調、音源に合わせた伸縮、句読点の休止長、読み上げの動きに合わせた伸縮 |
| 発音 | 英語機能語の弱形 |
| Classic UTAU | 使用するResamplerとWavtool |
| DiffSinger | 拡散ステップ数や表現力（[詳細](diffsinger.md)） |

## 辞書設定

「設定」→「辞書設定...」で、固有名詞や略語の読みを修正できます。

1. 「表記」に読みを変えたい文字列を入力します。
2. 「読み」に発音を入力します。日本語はひらがなまたはカタカナ、英語はARPAbet、中国語は声調付きPinyinを使います（[読みを指定する](multilingual.md#読みを指定する)）。
3. 「適用」または「OK」で反映します。

| 表記 | 読み |
| --- | --- |
| `UtauTTS` | `うたうてぃーてぃーえす` |

反映すると、入力済みの文章も新しい読みで再解析されます。

## 書き出し

有効にすると、WAVと同じ場所へTXT／LABも保存します。初期状態では無効です。

| 項目 | 内容 |
| --- | --- |
| WAVと一緒にテキストファイルを保存する | 入力文章を`.txt`で保存 |
| テキストファイルの文字コード | UTF-8またはShift_JIS（CP932） |
| WAVと一緒に.labファイルを保存する | 音素の開始・終了時刻をHTK形式の`.lab`で保存 |

一括WAV保存とexo出力にも適用されます。LABはPSDToolKitなどのリップシンクに利用できます。

## 表示と動作

- テーマ、表示言語、更新通知、ログ、音声キャッシュなどを変更できます。
- FFmpegのパスにはQt Multimedia用プラグインとコーデックを含むフォルダを指定し、変更後に再起動してください。
- 自動プレビューを有効にすると、イントネーションや長さの編集後に自動で再合成します。
- 「拡張編集で数値設定を表示する」を有効にすると、原音ごとの詳細な設定を数値で調整できます。初期状態では無効です。
- プレリリース版は「プレリリース版も確認する」が有効な場合だけ更新候補になります。

## ショートカット

欄を選んでキーを押すと割り当てられます。`Backspace`で解除できます。同じキーを複数の操作へ割り当てることはできません。

初期ショートカットは[GUIの使い方](gui.md#標準ショートカット)にあります。`Ctrl+Z`／`Ctrl+Y`では、基本編集と拡張編集で行った変更を元に戻したり、やり直したりできます。

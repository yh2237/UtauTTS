# 設定

「設定」→「設定...」で、新しい文章カードの初期値とアプリ全体の動作を変更できます。「適用」は変更を反映して画面を開いたままにし、「OK」は反映して閉じます。「キャンセル」は未保存の変更を破棄します。

設定は実行ファイルと同じ階層の`config.ini`へ保存されます。

## 音声合成

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| 音源 | 自動（一覧の先頭） | 新しいカードで使うボイスバンク |
| 抑揚 | 2.00 | 自動イントネーションの強さ |
| モーラ長 | 120 ms | 自動値がないモーラの長さ |
| 休止長 | 180 ms | 句読点などの休止時間 |
| 原音形式 | 自動 | 原音の選択方式 |
| 抑揚モデル | `frame-intonation-tcn-v9.1-t` | 自動イントネーションのモデル。英語では`english-intonation-v1`へ自動で切り替わります。`なし`では予測しません |
| Renderer | `utautts-world-phrase` | 原音を接続してWAVにする方式 |
| 音高 | `C4` | 新しいカードの基準音高 |
| 文頭の長さ | 自動 | 最初の原音に確保する先行発声 |

文頭の長さは「自動」のほか、5〜300 msの固定値にもできます（0は自動を表すため固定値には使えません）。先頭が欠ける音源では長く、余計なノイズを拾う音源では短くします。カードごとの設定は[GUIの使い方](gui.md#カードごとの合成設定)で変更します。

## Renderer設定

設定ウィンドウにはRendererごとのタブがあり、そのRendererが持つ詳細な設定を変更できます。設定した値は`config.ini`へ保存されます。

モーラ長・休止長・文頭の長さ・抑揚は新しいカードの既定値になり、カードごとの設定がそれを上書きします。それ以外の韻律補正（「文脈に応じた長さ」「文末の音調」「句読点の休止長を文脈化」「英語機能語の弱形」）はすべての合成に適用され、初期状態で有効です。

Renderer固有の項目もここで設定します。

- **Classic UTAU**: 使用するresamplerとwavtoolを選びます。
- **DiffSinger**: 拡散ステップ数や表現力などの推論パラメータを調整します。

RendererとClassic UTAUツールの追加方法は[モデル／Rendererプラグイン](plugins.md)を参照してください。外部ツールは信頼できる配布元のものだけを使用してください。

## 辞書設定

「設定」→「辞書設定...」で、表記と読みの対応を登録します。自動読みが誤る固有名詞や略語の修正に使います。

1. 「表記」に文章中で置き換えたい文字列を入力します。
2. 「読み」に読み上げたいひらがなまたはカタカナを入力します。
3. 「適用」で反映します。「OK」なら反映して画面を閉じます。

| 表記 | 読み |
| --- | --- |
| `UtauTTS` | `うたうてぃーてぃーえす` |

辞書は`config.ini`へ保存され、次回起動時も使われます。反映すると入力済みの文章も新しい辞書で再解析されます。

## 書き出し

WAVと同じ場所へ付随ファイルを保存できます。初期状態では無効です。

| 項目 | 内容 |
| --- | --- |
| WAVと一緒にテキストファイルを保存する | 入力文章を`.txt`で保存 |
| テキストファイルの文字コード | UTF-8またはShift_JIS（CP932） |
| WAVと一緒に.labファイルを保存する | 音素の開始・終了時刻をHTK形式の`.lab`で保存 |

一括WAV保存とexo出力にも適用されます。LABはPSDToolKitなどのリップシンクに利用できます。

## 表示と動作

- テーマ、表示言語、外部FFmpegのパス、更新通知、プレリリース版の確認、ログ、音声キャッシュ、自動プレビューを設定します。
- FFmpegのパスにはQt Multimedia用プラグインとコーデックを含むフォルダを指定し、変更後に再起動してください。
- キャッシュはアプリ終了時や音源の再読込時に削除されます。
- 自動プレビューを有効にすると、イントネーションや長さの編集後に自動で再合成します。
- 「拡張編集で数値設定を表示する」を有効にすると、原音ごとの詳細な設定を数値で調整できます。初期状態では無効です。
- プレリリース版は「プレリリース版も確認する」が有効な場合だけ更新候補になります。

## ショートカット

欄を選んでキーを押すと割り当てられます。`Backspace`で解除できます。同じキーを複数の操作へ割り当てることはできません。

初期ショートカットは[GUIの使い方](gui.md#標準ショートカット)にあります。`Ctrl+Z`／`Ctrl+Y`では、基本編集と拡張編集で行った変更を元に戻したり、やり直したりできます。

# Web版（ブラウザ）

UtauTTSはインストールせずにブラウザでも使えます。[Web版エディタ](https://utautts.yh.contact/editor/) を開いてください。合成エンジンはデスクトップ版と同じで、WebAssemblyのWorkerとして動きます。初回はエンジンとモデルの読み込みに時間がかかります。

## デスクトップ版との違い

| 項目 | デスクトップ版 | Web版 |
| :--- | :--- | :--- |
| 起動 | 実行ファイルを起動する | ブラウザでWeb版エディタを開く |
| 音源の追加 | ZIPを選ぶ。`voice/` にフォルダを置くこともできる | ZIPを選ぶ。ブラウザの保存領域に置かれ、再読み込みすると消える |
| 音源フォルダを開く | あり | なし |
| プロジェクトの保存 | 保存先を選ぶ | 名前を付けてダウンロードする |
| プロジェクトを開く | ファイルを選ぶ（OSのダイアログ） | ファイルを選ぶ（ブラウザのダイアログ） |
| 最近使ったプロジェクト | あり | なし（一覧は常に空） |
| WAVの保存 | 保存先を選ぶ | ダウンロードする |
| WAVの一括保存 | フォルダを選んで保存する | ZIPにまとめて1回でダウンロードする |
| USTXの書き出し | 保存先を選ぶ | ダウンロードする |
| exoの書き出し | あり | なし |
| 診断情報の書き出し | 保存先を選ぶ | ダウンロードする |
| 参照索引の作成 | 設定画面から作成できる | 作成できない（抑揚の予測は波形合成で行う） |
| 音声出力デバイス | 選べる | 選べない（一覧が空） |
| FFmpegのパス | 設定できる | 設定項目が出ない |
| 初回起動の案内 | あり | なし |
| 未保存のまま閉じる | 終了時に確認する | タブを閉じるときに確認する |
| アプリ内の更新 | あり | なし（リリースページから手動で更新する） |
| 画面 | 独立したウィンドウ | ブラウザのタブ内。タッチ端末ではモバイル向けの配置になる |

## 保存と読み込み

- プロジェクトとWAVはダウンロードとして保存されます。保存先はブラウザの設定に従います。
- 作業内容はブラウザの保存領域に自動保存されます。再読み込みすると、復元するか確認します。

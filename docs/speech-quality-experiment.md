# 発話タイミングと音源校正（実験）

発話タイミングと音源校正は原音の長さや接続を調整する機能です。日本語では子音の種類や句末に応じて長さを変えます。音源校正は各言語で使う原音の安定した有声区間を調べて接続位置を補正します。

既定では無効です。効果は音源によって異なるため同じ文章で有効時と無効時を聞き比べてください。

## 有効にする

| 入口 | 設定 |
| --- | --- |
| GUI | 開発者モードで発話の「発話タイミング・音源校正（実験）」を有効にする |
| CLI | `--speech-timing`を指定する |
| HTTP API | 合成リクエストに`"speech_timing": true`を指定する |

GUIの設定は発話ごとにプロジェクトへ保存されます。プレビューにも適用されます。

CLIでは次のように実行します。音源パスは手元のボイスバンクに置き換えてください。開発環境では`utautts-cli`の代わりに`go run ./cmd/utautts-cli`を使えます。

```powershell
utautts-cli --voicebank "./voice/japanese-bank" --reading "カサ、キク。" --speech-timing --renderer waveform --out speech.wav --plan-out speech.plan.json
```

## 調整する内容

日本語では子音ごとの時間配分と句末の長さを調整します。母音が無声化しやすい箇所は短くします。録音された母音を無声音へ変換する処理は行いません。

手動指定したモーラ長を優先します。長さを予測する抑揚モデルを使う場合や`--prosody-pitch-only`の指定時は規則による長さ変更を行いません。

音源校正は`oto.ini`の固定部付近にある安定した有声区間を探します。合成時の固定部を元の値から最大±20 msの範囲で補正します。判定の信頼度が低い原音は元の値を使います。`oto.ini`や原音WAVは書き換えません。

## 対応範囲

音源校正は局所的な波形の特徴に基づく補正です。音素境界を正確に推定する機能ではありません。収録形式や録音状態によっては接続が不自然になることもあります。

読み間違いや音源にない発音はこの設定では補えません。英語・中国語の読みと音源形式は[多言語TTS](multilingual.md)を参照してください。長さや抑揚を直接調整する方法は[イントネーションとモーラ長の編集](manual-pitch.md)にあります。

開発者向けの比較手順と合成計画の診断項目は[読み上げ品質の評価](../tools/evaluation/README.md)を参照してください。

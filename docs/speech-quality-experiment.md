# 発話タイミング補正

この機能は、音源の録音範囲と発話の長さが合わない場合に、原音の配置と接続を補正します。日本語では子音の種類や句末に応じて時間を調整し、各言語で安定した有声区間を探して接続位置を補正します。

GUIで新しく作る発話では無効です。既存プロジェクトで明示した設定は維持されます。CLIとHTTP APIでは、指定した発話だけで有効になります。効果は音源の収録形式と録音状態によって異なります。

日本語の連続音では、録音済みのVCV境界を優先します。補正を有効にすると、単独音とVCVの配置を調整し、重なり区間で音声フレームが欠けた場合は条件を満たす範囲だけ補間します。多言語の連続音では、音源の有声区間を使った通常の補正を行います。

## 有効にする

| 入口 | 設定 |
| --- | --- |
| GUI | 右側の設定メニューで「タイミング補正」を有効にする。新しい発話では初期状態で無効 |
| CLI | `--speech-timing`を指定する |
| HTTP API | 合成リクエストに`"speech_timing": true`を指定する |

GUIの設定は発話ごとにプロジェクトへ保存され、プレビューにも適用されます。

CLIの例です。音源のパスは使用するボイスバンクに置き換えてください。開発環境では`utautts-cli`の代わりに`go run ./cmd/utautts-cli`を使えます。

```powershell
utautts-cli --voicebank "./voice/japanese-bank" --reading "カサ、キク。" --speech-timing --renderer waveform --out speech.wav --plan-out speech.plan.json
```

## 補正する内容

日本語では子音ごとの時間配分と句末の長さを調整します。母音が無声化しやすい箇所は短くします。録音された母音を無声音へ変換する処理は行いません。

手動指定したモーラ長を優先します。長さを予測する抑揚モデルを使う場合や`--prosody-pitch-only`を指定した場合は、規則による長さ変更を行いません。

音源校正では、`oto.ini`の固定部付近にある安定した有声区間を探します。CVは固定部を元の値から最大±20 msの範囲で補正します。VCVは先行発声と固定部をモーラ長に合わせて補正し、母音末尾を確保します。信頼度が低い原音は元の値を使います。入力ファイル: `oto.ini`と原音WAV。変更対象: 合成時の補正値。

`waveform`では校正できた原音の子音側と母音側を分けて伸縮します。`oto.ini`の先行発声位置を母音開始の目安にし、破裂音の短い立ち上がりを残します。指定した発話の長さとモーラの開始時刻は保ちます。十分な区間を確保できない原音は通常の伸縮処理を使います。

子音を挟まない同じ母音の連続では接続補修を試します。合成後の波形の相関と接続の不連続を確認し、条件を満たした場合だけ補修を採用します。自動補修の対象: 同じ母音の連続。異なる母音、子音、休止をまたぐ箇所: 対象外。

`utautts-world-phrase`では、単独音または`--speech-timing`を指定した発話で区間別の伸縮と自動接続補修を使います。VCVでは補正後の先行発声と固定部をWORLDの時刻写像へ渡します。WORLDの音響特徴を区間ごとの時間軸へ配置し、指定したピッチ曲線を使います。同じ母音の接続では前後20 msの有声区間を調べ、スペクトルの急変が小さくなる場合だけ補修します。補修対象外: 無声区間や別の原音が重なる箇所。

WORLD版の構成: 本体と`utautts-worldline-bridge`。本体とbridgeのjob versionが異なる場合はエラーになります。CLIの指定: `--renderer utautts-world-phrase --speech-timing`。追加モデル: なし。

## 対応範囲

音源校正の対象: 局所的な波形特徴。音素境界の厳密推定は対象外です。収録形式や録音状態によっては接続が不自然になることがあります。

対応範囲外: 読み間違いと音源にない発音。英語と中国語の読み、音源形式: [日本語・英語・中国語の読み上げ](multilingual.md)。長さや抑揚の直接調整: [イントネーションとモーラ長の編集](manual-pitch.md)。

比較手順と合成計画の診断項目は[読み上げ品質の評価](../tools/evaluation/README.md)を参照してください。

# 発話タイミングと音源校正

発話タイミングと音源校正は原音の長さや接続を調整する機能です。日本語では子音の種類や句末に応じて長さを変えます。音源校正は各言語で使う原音の安定した有声区間を調べて接続位置を補正します。

GUIの新規発話では有効です。保存済みプロジェクトで明示した設定は維持します。CLIとAPIでは明示して有効にします。効果は音源によって異なります。

連続音のVCV境界補正はこの設定に関わらず通常の合成へ適用します。`speech_timing`を有効にすると単独音やCVの発話タイミング補正も加わります。

## 有効にする

| 入口 | 設定 |
| --- | --- |
| GUI | 新規発話では有効。「詳細設定」の「タイミング補正」で変更する |
| CLI | `--speech-timing`を指定する |
| HTTP API | 合成リクエストに`"speech_timing": true`を指定する |

GUIの設定は発話ごとにプロジェクトへ保存されます。プレビューにも適用されます。

CLIでは次のように実行します。音源パスは手元のボイスバンクに置き換えてください。開発環境では`utautts-cli`の代わりに`go run ./cmd/utautts-cli`を使えます。

```powershell
utautts-cli --voicebank "./voice/japanese-bank" --reading "カサ、キク。" --speech-timing --renderer waveform --out speech.wav --plan-out speech.plan.json
```

## 調整する内容

日本語では子音ごとの時間配分と句末の長さを調整します。母音が無声化しやすい箇所は短くします。録音された母音を無声音へ変換する処理は行いません。

手動指定したモーラ長を優先します。長さを予測する抑揚モデルを使う場合や`--prosody-pitch-only`の指定時は規則による長さ変更を行いません。

音源校正は`oto.ini`の固定部付近にある安定した有声区間を探します。CVは固定部を元の値から最大±20 msの範囲で補正します。VCVは長い録音の先行発声と固定部をモーラ長に合わせて補正し、母音末尾を確保します。判定の信頼度が低い原音は元の値を使います。`oto.ini`や原音WAVは書き換えません。

`waveform`では校正できた原音の子音側と母音側を分けて伸縮します。`oto.ini`の先行発声位置を母音開始の目安にして破裂音の短い立ち上がりを残します。指定した発話の長さとモーラの開始時刻は保ちます。十分な区間を確保できない原音は通常の伸縮処理を使います。

子音を挟まない同じ母音の連続では接続補修も試します。合成後の波形で候補を比較し波形の相関と接続の不連続が条件を満たした場合だけ採用します。異なる母音・子音・休止をまたぐ自動補修は行いません。

`utautts-world-phrase`でも区間別の伸縮と自動接続補修を使えます。VCVでは補正後の先行発声と固定部をWORLDの時刻写像へ渡します。WORLDの音響特徴を参照する時刻を区間ごとに変えます。ピッチは指定された曲線を使います。同じ母音の接続では前後20 msの有声区間を調べてスペクトルの急変が小さくなる場合だけ補修します。無声区間や別の原音が重なる箇所は補修しません。

WORLD版を使うには本体と`utautts-worldline-bridge`を両方ビルドしてください。本体とbridgeのjob versionが異なる場合はエラーになります。CLIの指定例は`--renderer utautts-world-phrase --speech-timing`です。追加の依存関係やモデルは不要です。

`utautts-world-phrase`ではこの区間別伸縮と接続補修を適用します。発話の長さ調整と音源校正は従来どおり使えます。

## 対応範囲

音源校正は局所的な波形の特徴に基づく補正です。音素境界を正確に推定する機能ではありません。収録形式や録音状態によっては接続が不自然になることもあります。

読み間違いや音源にない発音はこの設定では補えません。英語・中国語の読みと音源形式は[多言語TTS](multilingual.md)を参照してください。長さや抑揚を直接調整する方法は[イントネーションとモーラ長の編集](manual-pitch.md)にあります。

開発者向けの比較手順と合成計画の診断項目は[読み上げ品質の評価](../tools/evaluation/README.md)を参照してください。

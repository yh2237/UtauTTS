# 日本語・英語・中国語の読み上げ

UtauTTSは、日本語に加え、英語・中国語の音声合成にも対応しています。使用する音源に合わせて言語と発音形式を指定してください。

## 言語と発音形式の対応

| 言語 | `language` | `phonemizer` | 入力テキスト例 |
| :--- | :--- | :--- | :--- |
| **日本語** | `ja` | `ja-kana`（既定） | 通常の日本語文、またはひらがな読み |
| **英語** | `en` | `en-arpasing`（既定） | 英文、またはARPAbet読み |
| **英語** | `en` | `en-delta` | 英文、またはARPAbet読み |
| **英語** | `en` | `en-vccv` | 英文、またはARPAbet読み |
| **英語** | `en` | `en-cv` | 英文、またはARPAbet読み（C+V音源用） |
| **中国語** | `zh` | `zh-cvvc`（既定） | 中国語簡体字文、または声調付きPinyin |

英語はどの発音形式でも同じ方式で合成します。発音形式は編集画面でのモーラの区切り方を決めます。

- **GUI**: 音源と言語を選ぶと、発音形式は通常 `自動` で最適化されます。
- **CLI**: `--language` と `--phonemizer` を指定します。
  ```powershell
  utautts-cli --voicebank "./voice/english-bank" --language en --phonemizer en-arpasing --text "Hello world." --out hello.wav
  ```

## 読み（音素列）の直接指定

自動解析による読みが意図と異なる場合は、読み欄または辞書設定で発音記号を直接指定できます（CLIでは `--reading` オプション）。

| 言語 | 読み指定の例 | 区切り規則 |
| :--- | :--- | :--- |
| **英語** | `HH AH0 L OW1 \| W ER1 L D \| SP` | 半角空白で音素区切り、`\|` で単語境界、`SP` で休止。末尾数字は強勢（0:無強勢、1:第1強勢） |
| **中国語** | `ni3 hao3 \|` | 半角空白で音節区切り、末尾数字で声調（1〜5）、`\|` で休止 |

英語の発音は語ごとにmisakiの英語辞書を引いて決めます。辞書にない語と、利用者辞書に登録した語はARPAbetの読みを使います。読みを直接指定すると、すべての語を指定した読みで発音します。

## 長さと抑揚

- **英語**:
  - 参照用の音声合成（Kokoro-82M）の読みから、長さと抑揚を決めます。仕組みは [英語の読み上げ](how-utautts-speaks.md#9-英語の読み上げ) にあります。
  - モーラ長の設定は話速（120msで1倍）、抑揚の強さはF0の動きの幅（4で1倍）、音高はF0の中心（自動なら音源のF0の中央値）に使います。
  - 手動で直したモーラ長と抑揚は、英語ではまだ反映しません。
- **中国語**:
  - 数値や年号の読み分け、第三声の変調（sandhi）や軽声の調整を自動処理します。
  - 声調抑揚モデル `tone-intonation-zh-v1` により、四声の基本ピッチに文脈補正を加えます。

## 音源の索引（英語）

英語は原音をつながず、参照音声に近いフレームを音源の録音から選んで合成します。選ぶ前に、音源ごとに録音を解析した索引を作ります。英語向けの音源は、音源の読み込み時に索引を作ります。作成中は読み込みの表示に進み具合が出ます（テトの英語音源で約3分）。それ以外の音源は、英語を初めて合成するときに作ります。

Web版では英語を合成できません。

---

## 原音の配置（CPU版 WORLD）

中国語の音節は日本語と同じく、`oto.ini` の先行発声・固定範囲・オーバーラップに沿って原音を配置します。

# 多言語TTS（試験実装）

CLI、Server、プロジェクトの各発話では、次の言語とphonemizerを選べます。`phonemizer`を省略すると言語ごとの既定値になります。

| 言語 | `language` | phonemizer | 既定値 | 入力 |
| --- | --- | --- | --- | --- |
| 日本語 | `ja` | `ja-kana` | `ja-kana` | 日本語文章またはかな読み |
| 英語 | `en` | `en-arpasing` | `en-arpasing` | 英文またはARPAbet読み |
| 英語 | `en` | `en-delta` |  | 英文またはARPAbet読み |
| 英語 | `en` | `en-vccv` |  | 英文またはARPAbet読み |
| 中国語 | `zh` | `zh-cvvc` | `zh-cvvc` | 中国語文章または声調付きPinyin |

GUIでは発話カードの言語／phonemizer欄を使います。現在は試験実装として開発者モードで表示されます。DiffSinger音源は別の音源形式で、詳細は[DiffSinger](diffsinger.md)を参照してください。

CLIでは次のように指定します。

```bash
utautts-cli \
  --voicebank ./voice/english-bank \
  --language en \
  --phonemizer en-arpasing \
  --text "Hello world" \
  --renderer waveform \
  --out hello.wav
```

読みを直接渡す場合は、英語はARPAbet、中国語は空白区切りのPinyinを使います。`|`は単語または句の区切りです。英語の`SP`、中国語の`|`は休止になります。

英語のテキスト入力では句読点を休止として残します。ARPAbetを直接指定する場合、`|`は単語の区切り、`| SP |`は休止として扱います。ARPAsingでは単語間の音素を接続し、休止位置で発話の終端・始端へ切り替えます。

日本語の抑揚モデルは英語・中国語には適用しない。英語には規則による暫定的な抑揚処理があり、明示された強勢と子音語尾を長さへ反映し、フレーズ内の音高変化を加える。音高変化はピッチ処理が有効で抑揚の強さが0より大きい場合に使う。専用の学習済み英語モデルではなく、文の意味に応じた強調までは扱わない。現在の英語G2Pは強勢情報を返さないため、強勢を指定するには辞書または`AH0`、`AE1`などを含むARPAbet読みを使う。

中国語はピンインの声調と三声の連続を使って音高曲線を作る。文脈に応じた読みや発話リズムの推定は限定的。

音源にない子音や接続を補って生成する機能はありません。音が欠ける場合は合成計画のaliasと原音候補を確認してください。語尾の原音が一つ見つからなくても、後続の候補の探索は続けます。

# 日本語以外の読み上げ

UtauTTSは日本語に加えて、英語・中国語・スペイン語・ポルトガル語も合成できます。使う音源に合わせて、言語と発音形式を指定してください。

## 言語と発音形式

| 言語 | `language` | `phonemizer` | 入力テキストの例 |
| :--- | :--- | :--- | :--- |
| 日本語 | `ja` | `ja-kana`（既定） | 日本語の文、またはひらがなの読み |
| 英語 | `en` | `en-arpasing`（既定） | 英文、またはARPAbetの読み |
| 英語 | `en` | `en-delta` | 英文、またはARPAbetの読み |
| 英語 | `en` | `en-vccv` | 英文、またはARPAbetの読み |
| 英語 | `en` | `en-cv` | 英文、またはARPAbetの読み（C+V音源用） |
| 中国語 | `zh` | `zh-cvvc`（既定） | 中国語の簡体字の文、または声調付きのPinyin |
| スペイン語 | `es` | `es-syllable`（既定） | スペイン語の文、または音節の読み |
| ポルトガル語（ブラジル） | `pt` | `pt-syllable`（既定） | ポルトガル語の文、または音節の読み |

日本語は波形合成で、英語・中国語・スペイン語・ポルトガル語は参照照合で合成します（CLIとHTTP APIでは、英語も波形合成を指定できます）。英語の発音形式で変わるのは、編集画面でのモーラの区切り方です。参照照合で初めて使う音源は、録音を解析して索引を作るため時間がかかります。言語が英語と判定された音源は、読み込んだときに作り始めます。Web版で合成できるのは日本語だけです。

GUIでは、発音形式は通常`自動`のままで、音源に合うものが選ばれます。CLIでは`--language`、`--phonemizer`、`--method`を指定します。

```powershell
utautts-cli --voicebank "./voice/english-bank" --language en --phonemizer en-arpasing --method reference-matching --text "Hello world." --out hello.wav
```

## 読みを直す

自動の読みが意図と違うときは、辞書設定で発音記号を直接指定できます。CLIでは`--reading`で指定します。

| 言語 | 読みの例 | 区切りの規則 |
| :--- | :--- | :--- |
| 英語 | `HH AH0 L OW1 \| W ER1 L D \| SP` | 半角空白で音素を、`\|`で単語を区切り、`SP`は休止。母音の末尾の数字は強勢（0は強勢なし、1は第1強勢） |
| 中国語 | `ni3 hao3 \|` | 半角空白で音節を区切り、末尾の数字は声調（1〜5）。`\|`は休止 |
| スペイン語・ポルトガル語 | `ˈo.la , kˈe tˈal ?` | 半角空白で語を、`.`で音節を区切る。記号はKokoroの音素記号で、母音の前の`ˈ`は第1強勢、`ˌ`は第2強勢。`,` `.` `?`は休止 |

英語の発音は語ごとにmisakiの英語辞書を引き、無い語はCMUdictとLibriSpeechの辞書を引いて決めます。どれにも無い語、利用者辞書に登録した語、読みを直した語は、ARPAbetの読みから発音します。読みを直して語の数が本文と変わったときは、すべての語を読みから発音します。

## 長さと抑揚

英語・中国語・スペイン語・ポルトガル語では参照用の音声合成（Kokoro-82M）の読みから長さと抑揚を決めます。仕組みは[参照照合](how-utautts-speaks.md#9-参照照合)にあります。

- モーラ長の設定は話速に使います。120msで1倍です。
- 抑揚の強さはF0の動きの幅に使います。4で1倍です。
- 音高はF0の中心に使います。自動なら音源のF0の中央値です。
- 手動で直したモーラ長は、Kokoroを読み直さず、選んだフレームの並びを時間方向に伸縮して反映します。
- 手動で直した抑揚はKokoroの抑揚からのずれとして足します。
- 拡張編集の`PIT`と`VOL`は、そのモーラの区間の音高と音量に掛けます。

中国語では数値や年号を読み分け、百分率は「百分之〜」と読みます。第三声などの変調（sandhi）を反映した読みを参照用の音声合成に渡します。

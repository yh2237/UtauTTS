# 日本語以外の読み上げ

UtauTTSは日本語に加えて、英語・中国語・スペイン語・ポルトガル語も合成できます。使う音源に合わせて、言語と発音形式を指定してください。

## 言語と発音形式

| 言語 | `language` | `phonemizer` | 入力テキストの例 |
| :--- | :--- | :--- | :--- |
| 日本語 | `ja` | `ja-kana`（既定） | 日本語の文、またはひらがなの読み |
| 英語 | `en` | `en-arpasing`（既定） | 英文、またはARPAbetの読み |
| 英語 | `en` | `en-delta` | 英文、またはARPAbetの読み |
| 英語 | `en` | `en-vccv` | 英文、またはARPAbetの読み |
| 英語 | `en` | `en-cv` | 英文、またはARPAbetの読み（C+V音源用） |
| 中国語 | `zh` | `zh-cvvc`（既定） | 中国語の簡体字の文、または声調付きのPinyin |
| スペイン語 | `es` | `es-syllable`（既定） | スペイン語の文、または音節の読み |
| ポルトガル語（ブラジル） | `pt` | `pt-syllable`（既定） | ポルトガル語の文、または音節の読み |

日本語は波形合成、英語・中国語・スペイン語・ポルトガル語は参照照合で合成します（CLIとHTTP APIでは英語も波形合成を指定できます）。英語で発音形式を変えると、編集画面でのモーラの区切り方が変わります。

参照照合で初めて使う音源は、録音を解析して索引を作るため時間がかかります。英語と判定された音源は、読み込み時に索引の作成を自動で始めます。Web版では参照照合を初めて使うときにモデル（英語・スペイン語・ポルトガル語で約310MB、中国語は約210MB）をダウンロードし、作成した索引をブラウザに保存します。

GUIでは発音形式を `自動` のままにしておけば、音源に合うものが選ばれます。CLIでは `--language`、`--phonemizer`、`--method` を指定します。

```powershell
utautts-cli --voicebank "./voice/english-bank" --language en --phonemizer en-arpasing --method reference-matching --text "Hello world." --out hello.wav
```

## 読みを直す

自動生成された読みが意図と違うときは、辞書設定で発音記号を直接指定できます（CLIでは `--reading`）。

| 言語 | 読みの例 | 区切りの規則 |
| :--- | :--- | :--- |
| 英語 | `HH AH0 L OW1 \| W ER1 L D \| SP` | 半角空白で音素を、`\|`で単語を区切り、`SP`は休止。母音の末尾の数字は強勢（0は強勢なし、1は第1強勢） |
| 中国語 | `ni3 hao3 \|` | 半角空白で音節を区切り、末尾の数字は声調（1〜5）。`\|`は休止 |
| スペイン語・ポルトガル語 | `ˈo.la , kˈe tˈal ?` | 半角空白で語を、`.`で音節を区切る。記号はKokoroの音素記号で、母音の前の`ˈ`は第1強勢、`ˌ`は第2強勢。`,` `.` `?`は休止 |

英語の発音は語ごとにmisakiの英語辞書を参照し、ない語はCMUdictとLibriSpeechの辞書を参照して決めます。いずれにもない語、ユーザー辞書に登録した語、読みを修正した語はARPAbetの読みから発音します。読みを修正して語数が本文と変わった場合は、すべての語を読みから発音します。

## 長さと抑揚

英語・中国語・スペイン語・ポルトガル語では、参照用の音声合成モデル（Kokoro-82M）の読みから長さと抑揚を決めます。仕組みは [参照照合](how-utautts-speaks.md#9-参照照合) を参照してください。

- モーラ長の設定は話速に反映されます（120msで1倍）。
- 抑揚の強さはF0の変化幅に反映されます（4で1倍）。
- 音高はF0の中心に使います。自動の場合は音源のF0の中央値になります。
- 手動で変更したモーラ長はKokoroを読み直さず、選んだフレームの並びを時間方向に伸縮して反映します。
- 手動で変更した抑揚はKokoroの抑揚からの差分として加算します。
- 拡張編集の `PIT` と `VOL` はそのモーラ区間の音高と音量に掛けます。

中国語では数値や年号を読み分け、百分率は「百分之〜」と読みます。第三声などの変調（sandhi）を反映した読みを参照用の音声合成に渡します。

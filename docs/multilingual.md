# 多言語TTS（試験実装）

英語はARPAsing、デルタ式CVVC、Cz式VCCV、中国語はCVVCの原音選択に対応する。音源に合う言語とphonemizerを選ぶ必要がある。

英語のテキスト入力では句読点を休止として残す。ARPAbetを直接指定する場合、`|`は単語の区切り、`| SP |`は休止として扱う。ARPAsingでは単語間の音素を接続し、休止位置で発話の終端・始端へ切り替える。

日本語の抑揚モデルは英語・中国語には適用しない。英語には規則による暫定的な抑揚処理があり、明示された強勢と子音語尾を長さへ反映し、フレーズ内の音高変化を加える。音高変化はピッチ処理が有効で抑揚の強さが0より大きい場合に使う。専用の学習済み英語モデルではなく、文の意味に応じた強調までは扱わない。現在の英語G2Pは強勢情報を返さないため、強勢を指定するには辞書または`AH0`、`AE1`などを含むARPAbet読みを使う。

中国語はピンインの声調と三声の連続を使って音高曲線を作る。文脈に応じた読みや発話リズムの推定は限定的。

音源にない子音や接続を補って生成する機能はない。音が欠ける場合は合成計画のaliasと原音候補を確認する。語尾の原音が一つ見つからなくても、後続の候補の探索は続ける。

# 同梱音源

GUI版には、メカニカルガールが公式配布している「足立レイ UTAU音源 ver3.5.0」を初期音源として同梱します。利用条件は、音源内の文書と公式ガイドラインを確認してください。

## 利用条件

足立レイ音源の利用条件は、メカニカルガールの公式文書に定められています。

- [公式配布ページ](https://mechanicalgirl.jp/adachi-rei/)
- [キャラクター／音源使用ガイドライン](https://mechanicalgirl.jp/guidelines/)

## SHA-256

同梱音源の元になった公式配布ZIPのSHA-256です。

```text
B96D1B21145F22E573AFD9EC8AEAAD0EC9CBAEE581C2623C64ADDEB31DE46B3D
```

配布元アーカイブとの同一性はSHA-256で確認しています。音源に含まれる文書は変更せず、そのまま配布物へ収録しています。

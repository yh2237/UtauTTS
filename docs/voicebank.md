# 同梱音源について

UtauTTS GUI版には、初期音源としてメカニカルガール様が配布されている「足立レイ ver3.5.0」を同梱しています。

音源データの利用条件については、音源フォルダ内の文書および公式ガイドラインを必ずご確認ください。

## 公式ガイドライン
- [公式配布ページ](https://mechanicalgirl.jp/adachi-rei/)
- [キャラクター／音源使用ガイドライン](https://mechanicalgirl.jp/guidelines/)

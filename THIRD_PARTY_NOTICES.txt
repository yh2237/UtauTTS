OpenUtau worldline
==================

The Windows and Linux releases bundle a modified build of the worldline native
library from OpenUtau. The UtauTTS changes are recorded in
tools/worldline-parallel.patch, tools/world-thread-local.patch,
tools/worldline-permissive.patch, and tools/worldline-native-bridge.patch.
The permissive patch replaces the original GPL-licensed spline dependency with
an independently implemented natural cubic spline and excludes unused
audio-output code from the shared library. Neither the GPL spline implementation
nor that audio-output code is present in the distributed worldline binaries.

JSUT and jsut-label prosody data
================================

The bundled learned prosody models were trained from the JSUT Japanese speech
corpus. The GUI also includes 300 unchanged BASIC5000 sentences, arranged into
six prompt packs for manual prosody adjustment. The optional BASIC5000 HTS-style
labels come from https://github.com/sarulab-speech/jsut-label. The original corpus
and label files are not bundled in this release. Component text sources carry their own terms
(Wikipedia CC BY-SA 3.0, TANAKA corpus CC BY 2.0, and JSUT original sentences
CC BY-SA 4.0). Contributors and complete source
attribution are recorded in licenses/JSUT-DATA-AND-LABELS.txt, which is included
in the release license bundle.

The bundled JSON model files are licensed under CC BY-SA 4.0. The model-specific
notice is included as licenses/PROSODY-MODELS.txt and models/README.md. UtauTTS's
repository-level MIT License applies to the source code and does not override
the terms for models, prompts, voicebanks, or other third-party assets.


NVIDIA CUDA runtime (experimental source build)
===============================================

The source tree contains an experimental `utautts-world-phrase-cuda` build path,
but the formal Windows and Linux release packages remove that renderer and do
not include a CUDA runtime. If a custom package includes it, the CUDA toolkit
EULA, license, and build provenance must be included under licenses/CUDA. No
NVIDIA GPU driver is distributed by UtauTTS.
